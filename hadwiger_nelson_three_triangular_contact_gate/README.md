# Exact three-triangular-patch contact gate

This package exactly reconstructs and four-colours all 31,626 complete
physical supports of order at most 505 obtained by combining two individually
four-chromatic contact phases with a fixed 169-point triangular patch.

It is a restricted finite construction-family theorem, not a global bound and
not a record improvement.  See [PROOF.md](PROOF.md) for the precise family,
explicit residue colouring, scope, and reproduction command.
