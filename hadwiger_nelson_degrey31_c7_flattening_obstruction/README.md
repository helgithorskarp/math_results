The fixed 31-vertex de Grey graph `D31` has a visible cyclic automorphism of

## Theorem

Let `sigma` advance each of `A,B,D,E` by one subscript and fix `C,F,G`.
There is no map `p: V(D31) -> R^2` and isometry `T` such that

1. `T^7` is the identity;
2. `p(sigma(v)) = T(p(v))` for every vertex;
3. every edge of `D31` has image length one.

Indeed, `T` cannot be the identity because the `A` orbit is a seven-cycle.  A
nonidentity order-seven plane isometry is rotation through
`alpha = 2*pi*m/7`, `m=1,...,6`, about a unique centre `O`.  The fixed roles
`C,F,G` map to `O`.  Write

```
p(A_j) = r exp(i(theta + j alpha)),
p(B_j) =     exp(i(phi   + j alpha)).
```

The radius of `B` is one because `B_j C` is an edge.  The two edges from
`A_j` to `B_(j-1)` and `B_(j+1)` imply

```
cos(theta-phi+alpha) = cos(theta-phi-alpha) = r/2.
```

Since `sin(alpha)` is nonzero, `sin(theta-phi)=0`; hence `r^2=4 cos^2(alpha)`.
The edge `A_j A_(j+1)` also gives

```
r^2 = 1 / (4 sin^2(alpha/2)).
```

For `x=2 cos(alpha)`, these equations force

```
f(x) = x^3 - 2 x^2 + 1 = 0.
```

Every seventh-root trace `x` satisfies

```
g(x) = x^3 + x^2 - 2 x - 1 = 0.
```

But `f=(x-1)(x^2-x-1)`, while `g(1)=-1` and the remainder of `g` modulo
`x^2-x-1` is `x+1` (and the quadratic is nonzero at `-1`).  Thus
`gcd(f,g)=1`, a contradiction.

Only the `A` cycle, the `B-C` edges, and the `A-B` offset edges are needed for
this obstruction.
