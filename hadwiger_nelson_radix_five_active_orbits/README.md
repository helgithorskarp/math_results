# Exact-five free-action interface for `A5(z)`

This package combines the h4171 exact-five affine-pencil classification with
the h4175 reflection-axis closure for

```text
A5(z) = T + zT + z^2T + z^3T + z^4T,
T = {0,1,(1+i sqrt(3))/2}.
```

Among the 131,356 global pair-system representatives left by h4139 and
h4167, h4171 marked 128,616 as compatible with an exactly-five-active pencil.
Their setwise `D3` stabilizers have orders

```text
order 1: 126,660 systems
order 2:   1,956 systems
```

For curves of bidegrees `(k,k)` and `(l,l)` on `P1 x P1`, the intersection
bound is `2kl`. HN2 h4175 proves that `D3` acts freely on every possible
non-four-colourable physical parameter. Dividing the intersection bounds by
the pair stabilizers therefore reduces the exact-five non-four parameter-orbit
allowance from **7,585,472 to 3,767,184**. The 2,740 systems which h4171 says
require at least six active curves have allowance 79,520. The two parts sum to
HN2's whole-frontier allowance 3,846,704 exactly.

No pair system is deleted. These are upper bounds with intersection
multiplicity, not counts of distinct roots. The six-or-more-active branch is
not closed, no physical chromatic search is performed, and no improvement to
the 509-vertex record is established.

## Reproduction

From the repository root, using standard-library CPython 3.11.2:

```sh
python3 -B hadwiger_nelson_radix_five_active_orbits/verify.py --check-expected
python3 -O -B hadwiger_nelson_radix_five_active_orbits/verify.py --check-expected
python3 -B hadwiger_nelson_radix_five_active_orbits/produce.py \
  --out /tmp/hn-five-active-orbits.json \
  --export-interface /tmp/hn-five-active-orbit-interface.json
```

Output paths for the producer must not exist. The verifier independently
reconstructs the h4171 interface and the named `D3` action from Eisenstein
rows. A checked producer/verifier run generated byte-identical explicit
interfaces.

The 2,331,829-byte explicit interface is intentionally regenerated rather
than committed. Its file SHA-256 is
`be36cc09da60c4bba4c260f42c12b21b88c9dea4553a1ae0214870c0284b047e`.
Each row supplies a pair, its stabilizer mask in the named action order, its
`2kl` bound, and its stabilizer-orbit allowance. See [HANDOFF.md](HANDOFF.md)
and [PROOF.md](PROOF.md).

The new composition is author-checked and awaits independent review. h4165's
four-concurrence result was independently accepted at h4173 and h4167's
incidence exclusions at h4169. h4171 and h4175 remain explicit dependencies.
