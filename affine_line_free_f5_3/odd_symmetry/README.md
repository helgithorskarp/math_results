# Odd-order symmetry cannot produce a 71- or 72-point line-free set

**Computer-assisted theorem.** An affine order-three invariant subset of
$\mathbb F_5^3$ containing no complete affine line has at most **70 points**.
The included 70-point witness attains the bound.

**Structural consequence.** Every possible 71- or 72-point line-free set
has an affine automorphism group of order a power of two, at most **32**.
The group contains no central inversion. If it is nontrivial, the set is
affinely equivalent to one invariant under either
$(x,y,z)\mapsto(-x,y,z)$ or $(x,y,z)\mapsto(-x,-y,z)$.

The [full proof](PROOF.md) explains the complete order-three normal form,
finite reduction, two exhaustive algorithms, and elementary exclusions of
orders five and 31. The stronger order-32 conclusion also imports the
campaign's [low-plane theorem](../low_planes72/README.md) and
[two-eight-plane exclusion](../two_eight_planes72/THEOREM.md).
The local checker does not re-prove these imported results.

This eliminates every odd-order affine symmetry as a construction route.
It does not restrict arbitrary candidates to symmetric sets, exclude the
two remaining reflection families, or improve the global interval
$70\le r_5(\mathbb F_5^3)\le72$. Independent peer review is pending.

## Reproduce

Requires Python 3.10+ and a C++20 compiler named `g++`; tested with Python
3.11.2 and GCC 12.2. No third-party Python package, SAT solver, external
catalogue, or network access is needed. From the repository root:

```sh
python3 affine_line_free_f5_3/odd_symmetry/verify.py --check-expected
```

The verifier compiles both programs in a temporary directory. It checks
all three normalized 71/72 cases and both normalized 70-point boundary
cases. The [expected output](EXPECTED.json) reports:

* status `ODD_SYMMETRY_OBSTRUCTION_VERIFIED`;
* completion counts `0, 0, 0, 0, 32`;
* agreement on every one of the 32 positive-control tuples;
* direct verification of all 32 sets against all 775 affine lines;
* exact fixed-line normalization and distinct parallel-plane profile
  spectra for the included witness and the published Figure 4 control.

The canonical enumeration-record SHA256 is
`7edda13c008ef1ef557701edcd33e0754705ef2bd4d1383321cf3762415c8f31`.
For an address/undefined-behavior sanitizer replay:

```sh
python3 affine_line_free_f5_3/odd_symmetry/verify.py --sanitize --check-expected
```

Both full builds were run successfully and gave identical output.
Source and compact-evidence hashes are in [SHA256SUMS](SHA256SUMS).

## Evidence and trust boundary

[enumerate_constraints.cpp](enumerate_constraints.cpp) uses orbit
constraints generated by [model.py](model.py) and a table of forbidden
last-layer choices. [enumerate_lines.cpp](enumerate_lines.cpp) independently
generates actual planar point sets and all 625 transverse lines, checking
intersections of their incidence vectors. Its geometry does not come from
the first program's model file. Both enumerate every admissible tuple,
using only proved cardinality cuts. No solver verdict or incomplete
search is used.

These are two different exact representations implemented by the same
researcher, not independent peer validation. The trust boundary is the
written reduction, ordinary Python/C++ integer computation, and the
separately cited premises for the order-32 consequence. This is not a
proof-assistant formalization.

[witness70.json](witness70.json) gives point indices `25*x+5*y+z`.
Its plane spectrum proves that it is not affinely equivalent to
[the published Figure 4 control](../known70.json). It supplies a second
construction seed, with no claim of a new lower bound, complete
classification, or priority for this affine class.

dependencies, and scope of the novelty check.
