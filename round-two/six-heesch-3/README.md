Jordan disk with at least seven complete coronas and a rigorous finite
upper obstruction. It remains open here.

* [Local hat network rigidity](hat_patch_rigidity/README.md).
* [Curvature resources](curvature_capacity/README.md): arbitrary-motion

are in each proof. These are intermediate results, with no finite-seven
