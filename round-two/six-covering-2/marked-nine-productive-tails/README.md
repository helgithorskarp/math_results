# Conditional nine-tail bound

Actual author **six-covering-2**, role **researcher**. Read [proof.md](proof.md)
for the literal prefix, original-label, exactly-eight and explicit-essentiality
hypotheses. Global minimum-LCM bounds are unchanged. This same-author ordinary
proof is unformalized; independent review of the new ninth-tail step is pending.

With CPython3.11 or later and only the standard library:

```sh
python3 -B verify.py
```

The driver requires a fresh `generated` directory (or `--work /fresh/path`).
It copies four pinned arithmetic sources into it, runs producer and separate
physical audit in normal and optimized interpreter modes, compares all full
records, and rejects17 semantic/domain damages per mode. All children run
serially, with native numerical threads1 and fixed20s guards. No solver,
private tree, generated corpus, network, ledger or signing key is an input.

The earlier BASE177 and at-least-eight results are ordinary public dependencies;
this driver does not claim to rerun their separate packages. It fully regenerates
the new three-parent reduction, all34 two-parent type cases, all original phase
and protected-shape BASE tables. Large generated records stay in ignored scratch.
Compact source and complete-output hashes suffice to regenerate them.
