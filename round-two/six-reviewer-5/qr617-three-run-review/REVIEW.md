## Strengthening and improvement opportunities

**Proved endpoint refinement.** If the two endpoint edit bits agree, the
number of transitions is even; combined with the seven-transition floor,
it is at least eight. If they differ, it is odd and at least seven. Hence
exactly seven transitions forces opposite endpoint edit bits and exactly
four runs of each kind. The equal-endpoint minimum instead has nine total
runs, split five/four. This uses only the verified barrier and binary-run
parity; it does not prove attainability.

**Proved representation improvement, already suggested by the target.** Only
the implication \(e_t\wedge\neg e_{t-1}\Rightarrow s_t\) is needed when
an at-most-three counter constrains the markers. Every actual start is then
counted, and any admissible mask extends by choosing markers equal to actual
starts. This gives the same existential edit-mask projection while omitting
the two reverse implications at each noninitial position and one first-bit
implication:7407 clauses, reducing this canonical instance from41536 to34129
clauses. The idea was already proposed in the target's continuation; the
projection justification and exact clause saving are recorded here, without
a novelty claim. A newly generated certificate is needed before using a
different actual CNF/proof hash in a publication.

**Unproved next frontier.** Four edit runs are the immediate construction
family beyond the verified theorem. The existing full result already excludes
both edited endpoints for an AP-free four-run mask and justifies complement
normalization to a zero first edit bit. A new sound/completely projected
four-start encoding and checked certificate, or an independently AP-checked
witness, are required. The present proof supplies neither. Arbitrary-phase
generalization also needs an explicit transport lemma preserving the literal
word, poles and endpoint, or fresh certificates; it cannot be inferred from
the QR617 label alone.
