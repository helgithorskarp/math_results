# An eight-edge ceiling for one genuine three-Moser contact class

Let `M` be the standard seven-point Moser spindle and consider the 343 formal
points

\[
 M+uM+vM,\qquad |u|=|v|=1.
\]

Every possible non-Cartesian unit edge defines a Laurent contact polynomial in
`u` and `v`. After grouping identical polynomials up to an exact nonzero
scalar, every three-factor class that is not generated by three unit
displacements contains at most eight formal edges. The census bound is sharp:
exactly 96 such classes attain eight.

Classes of larger multiplicity do exist, but every one is generated by three
unit displacement vectors. The elementary unit-vector identity in
[PROOF.md](PROOF.md) shows that its contact locus is entirely a union of formal
collision loci. These classes therefore cannot supply edges to an injective
physical construction.

This is a restricted-architecture structural gate, not a chromatic-number
theorem: several distinct contact classes can meet at one phase, and classes
involving only one or two factors are outside the ceiling. It explains why a
dense candidate in this architecture must intersect contact curves rather
than optimize a single genuine three-factor curve. It does not improve the
509-vertex record and is not a global Hadwiger--Nelson bound.

The solver-free verifier computes the complete inventory twice in exact
arithmetic:

1. directly from all 58,653 unordered pairs of formal points; and
2. by multiplying the ordered one-factor difference multiplicities and then
   dividing by orientation.

The two complete dictionaries must agree entry by entry. Run with Python
3.11+ from this directory:

```sh
python3 verify.py > /tmp/hn-moser-contact-ceiling.json
cmp expected.json /tmp/hn-moser-contact-ceiling.json
sha256sum -c SHA256SUMS
```

The replay takes about 90 seconds on the validation host and uses only the
Python standard library. It imports the exact field arithmetic and displayed
Moser coordinates from the sibling
[`hadwiger_nelson_independent_moser_sum_collisions`](../hadwiger_nelson_independent_moser_sum_collisions/README.md)
package. This is author-side evidence pending independent review.
