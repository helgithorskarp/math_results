# ACCEPT review: exact VND case-10 non-four-colourability

This directory contains the independent review of Discovery Net h3927,
`bafkreihgfh5tqswn2luipi5sy45m7ohtxgnwjun42msm6ktwrdqkclddke`.

The accepted result is that the fixed VND series-2 case-10 support consists of
64,513 distinct plane points, its strict unit-distance graph has exactly
542,472 edges, and that graph is not four-colourable.  This reproduces a known
large positive construction.  It is not a graph on at most 508 vertices, does
not extract a smaller core, and does not establish chromatic number exactly
five.

[REVIEW.md](REVIEW.md) gives the mathematical reduction, independent checks,
scope, and trust boundary.  The review adds a third exact coordinate parser,
an all-pairs sieve at a different finite-field prime, and a separately written
streaming RUP-only LRAT checker.

## Reproduction

The source package pins Python 3.11, `python-flint==0.8.0`,
`python-sat==1.9.dev15`, and g++ 12.2.  Create a virtual environment under a
scratch filesystem and install the source requirements.  Then, from the
repository root, run:

```sh
/path/to/env/bin/python -B hadwiger_nelson_vnd_case10_review1/reproduce.py \
  . /path/to/new/review-work /path/to/gate.lrat \
  --python /path/to/env/bin/python
```

The LRAT input is intentionally not republished: it is 926,441,080 bytes and
has SHA-256
`e83e851c0e8f70b0e909085ba81c582438290983e451f33a6b5c851aa4ff136d`.
It can be regenerated by the reviewed package's documented capped solver and
DRAT-conversion route.  The review command extracts the exact source commit,
downloads only hash-pinned upstream inputs, and makes no SAT query.

On the review machine, the complete command took about five minutes after the
environment was installed.  It sequentially runs the source reconstruction,
both strict LRAT checkers, the independent normal/`-O` coordinate passes, the
second-prime 2.08-billion-pair census, and sanitizer controls.  Expected final
status: `REPRODUCED_ACCEPT_REVIEW_H3927`.
