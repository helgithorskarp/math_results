## Exact point and edge audit

Let

```text
t   = exp(pi i/12),
phi = (sqrt(6)+i sqrt(3))/3,
M1  = {0} union {t^j phi^k : 0<=j<24, -1<=k<=1},
M2  = {z in M1+M1 : |z|<=1},
M3  = M2+M1,
rho = -7/8+i sqrt(15)/8.
```

The support is `M3 union rho*M3`.  The source obtains counts
`|M1|=73`, `|M2|=865`, and `|M3|=32257`.  Its safe parser represents each
Cartesian coordinate over the basis

```text
1, sqrt(2), sqrt(3), sqrt(6), sqrt(5), sqrt(10), sqrt(15), sqrt(30)
```

with common denominator 96.  The basis is valid because the square classes of
2, 3, and 5 are independent.  A second submitted implementation reconstructs
the set in `Q[t]/(t^8-t^4+1)` with an adjoining `sqrt(5)` and matches all
points and all 132 unit-displacement classes.  The relation between the source
rotation and the paper's case-10 rotation follows from
`rho=t^11*conjugate(psi)` together with rotation and conjugation invariance of
`M3`.

The reviewer implementation imports none of this code.  A recursive-descent
parser independently evaluates every raw archive expression into the
eight-dimensional multiquadratic basis and matches all 64,513 coefficient
vectors entry by entry.  It proves their exact distinctness and checks every
one of the 542,472 declared edges by coefficient convolution.  The resulting
canonical hashes are

```text

edges   1cf734ec5d06549e8cf944d2ebdb709bf3e59f098e906f3d090a595929824c91.
```

For strict-edge completeness, the submitted scan maps the coefficient ring
to a ring modulo `1000000009`.  Every characteristic-zero unit pair must
survive that specialization; all survivors are then checked exactly.  Its
full 2,080,931,328-pair scan yields precisely the archived edge set with no
false positives.

The review repeats the complete census with a different prime,
`1000000271`, independently checked square roots of 2, 3, and 5, residues
generated by the new parser, and high-endpoint-major traversal.  The signed


## Four-colouring reduction

For each vertex `v` and colour `c` in `{0,1,2,3}`, the CNF variable is
`X(v,c)=4v+c+1`.  The formula contains one four-literal at-least-one clause
per vertex and, for every edge and colour, the binary clause prohibiting that
colour at both endpoints.  The actual unit triangle on vertices `0,1,5` is
pinned to colours `0,1,2`.

A proper four-colouring can be palette-permuted to meet those three pins and
satisfies the formula.  Conversely, any satisfying assignment gives each
vertex a nonempty set of true colours, while an edge's endpoint sets are
disjoint.  Choosing one true colour at each vertex is therefore a proper
four-colouring.  At-most-one clauses are unnecessary.

The independently regenerated and raw-graph-audited formula has

```text
variables      258,052
clauses      2,234,404
SHA-256  aa4305ebd561a52e89fe77738deee93c53f0c062a7715b879a51d0ada69b3bef.
```

## Independent LRAT verification

The 926,441,080-byte LRAT certificate has SHA-256
`e83e851c0e8f70b0e909085ba81c582438290983e451f33a6b5c851aa4ff136d`.
The submitted strict checker accepts it directly against the independently
regenerated CNF.

The reviewer checker is a separate C++ implementation with a buffered token
scanner and trail-reset assignments rather than the submitted string-token
and epoch-stamp implementation.  For each learned clause `C`, it assumes all
literals of `not C`, follows only positive active-clause hints, and requires
each effective hint to be unit or conflicting.  A learned clause is accepted
only after an actual conflict.  Thus the current formula implies every
accepted addition; deletion only weakens the active database.  The checked
empty clause proves the original CNF unsatisfiable.

The independent full pass accepts and recovers

```text

deletions        2,984,115
deletion records   377,609
hints used      100,631,926.
```

Ten named positive/negative cases pass in release and sanitizer builds.  An
additional 2,081 two-variable formula/hint-order cases are classified against
truth tables; all 757 satisfiable cases are rejected, and every accepted case
is unsatisfiable.  No SAT solver is called during review.

The excluded legacy `lrat-check` at revision

## Scope and trust boundary

This accepts a known 64,513-point positive source and its proof of
non-four-colourability.  It does not provide a five-colouring, so chromatic
number exactly five is not independently established.  It does not find a
subgraph on at most 508 vertices, extract a physical core, improve the
509-vertex record, or authorize another solver search.  The later retained-base
gate is not reviewed here.

The large CNF, DRAT, and LRAT files remain omitted from Git.  The verdict uses
the hash-pinned LRAT directly and therefore does not trust the solver answer or
need the DRAT-to-LRAT conversion for soundness.  Residual trust includes the
written algebra and encoding arguments, the upstream archive identity, both
independent code paths, Python/FLINT and C++ semantics, SHA-256, compiler,
operating system, and hardware.  This is a computer-assisted proof review, not
proof-assistant formalization.
