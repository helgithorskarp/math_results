# Complete Snail dihedral-nine family

The full dihedral-nine closure of the published 29-point Snail configuration,
centred at any seed vertex with reflection axis through any other seed vertex,
is always four-colourable. The complete classification of the **812 labelled
choices** is:

| Chromatic number | Cases |
|---|---:|
| 3 | 157 |
| 4 | 655 |

The graphs have **271–496 vertices** and **738–1,494 unit edges**. Thus this
entire target-sized construction family, including all its subgraphs, cannot
improve the 509-vertex record. These counts concern labelled choices, not
nonisomorphic graphs. No record improvement is established.

The [proof](PROOF.md) gives a reusable cubic rotation separation lemma. In
the degree-16 coordinate field, the full D9 graph is three rotated copies of
a D3 graph, meeting only at their common centre and with no other cross-copy
edges. Its chromatic number equals that of the smaller graph. The initial
505-point orbit bound sharpens to 496 because the designated axis point is
fixed by the reflection.

The source is Dúcz and Varga's
[Snail configuration](https://arxiv.org/html/2606.28157v1). Its ordinary
chromatic number is three, checked here. Their geometric fractional bound
uses a different invariant and is not a chromatic premise of this result.

## Check the proof

From the repository root, **CPython 3.11+ and the standard library** suffice:

```sh
python3 hadwiger_nelson_snail_dihedral/verify.py
python3 hadwiger_nelson_snail_dihedral/controls.py
python3 hadwiger_nelson_snail_dihedral/audit_geometry.py
```

The first command checks the complete positive colour certificate by a
finite-ring evaluation independent of the producer's geometry. It checks
3,548,735 same-colour address pairs and verifies the lower bounds by exact
coordinates and exhaustive three-colouring search on stored subgraphs.
Neither solver verdicts nor producer edge lists are proof inputs.

Expected output includes:

```text
verified: true
cases: 812
exactly_three_chromatic: 157
exactly_four_chromatic: 655
all_graphs_four_colourable: true
record_improvement: false
```

The geometry audit regenerates every graph in a second algebraic basis. It
checks 141,288 formal coordinates and 8,738,622 distinct-point pairs. The
controls compare the backtracking algorithm with chromatic-polynomial
inclusion–exclusion on all 1,100 simple labelled graphs through five vertices,
compare 256 basis products and 16 conjugates, and reject 20 malformed inputs.
Exact expected results and measured resource use are in [validation.json](validation.json).

## Reproduce certificate discovery

The optional producers use Python 3.11, `python-sat==1.9.dev15` and its
CaDiCaL 1.9.5 solver. They write expanded geometry outside the repository:

```sh
python3 hadwiger_nelson_snail_dihedral/produce.py --output /tmp/hn-snail
python3 hadwiger_nelson_snail_dihedral/classify.py \
  --producer /tmp/hn-snail --output /tmp/hn-snail/exact-certificate.json
python3 hadwiger_nelson_snail_dihedral/verify.py \
  --certificate /tmp/hn-snail/exact-certificate.json
python3 hadwiger_nelson_snail_dihedral/audit_geometry.py --producer /tmp/hn-snail
```

The discovery process first obtains four-colourings, then obtains either
three-colourings or smaller proposed obstructions. The proof checker verifies
both kinds directly. Obstruction minimality is neither required nor claimed.
The optional `produce.py --limit` switch is for pilots; incomplete output is
explicitly marked and rejected by the proof checker.

The frozen source table is in [seed.json](seed.json); all coordinates are
given exactly in [PROOF.md](PROOF.md). To repeat the independent reconstruction
of the authors' 29 symbolic coordinates, install `sympy==1.14.0`, obtain
`verts_sym.npy` from their [supplement](https://users.renyi.hu/~akos/ep1070/),
and run:

```sh
python3 hadwiger_nelson_snail_dihedral/import_source.py /path/to/verts_sym.npy
```

This optional importer checks the exact input hash and uses a closed
constructor allowlist. The normal proof checker needs neither NumPy,
SymPy, network access, nor the original supplement.

## Evidence and limits

The compact certificate has 88,302 bytes and SHA256

```text
c217efc0649faf986475dac157e7f2ac4bb992e4f4ac88a108e3217808d20dc3
```

All 812 expanded geometry files regenerated byte-identically. Every coordinate,
coincidence class and edge was also compared entry by entry with the independent
quadratic-tower implementation. The normal and optimized Python proof checks
agree. Source provenance is in [provenance.json](provenance.json).

The proof relies on the elementary field and gluing arguments in PROOF.md,
the explicit source table, and exact Python integer computations. It has not
been formally mechanized or externally reviewed. Expanded geometry, the
authors' large supplement archive, discovery models and logs remain private.

This family fixes the seed, unit scale, rotation order, seed centre and
seed-defined axis. It does not classify arbitrary centres or axes, other
rotation orders, unions of closures, or the much larger blow-up construction
from the source paper. The family is complete and is left at this boundary;
no further construction phase is opened by this package.
