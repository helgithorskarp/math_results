# A `C_5^2` automorphism obstruction for Ramsey `(5,5;43)`

Let `G` be a graph on 43 vertices with neither a clique nor an independent
set of order five. Then `Aut(G)` contains no subgroup isomorphic to
`C_5 x C_5` and no element of order 25. Consequently,

```text
25 does not divide |Aut(G)|.
```

This is a certified structural theorem, not a 43-vertex construction or an
improvement to the Ramsey bound.

## Forced action of `C_5^2`

The sibling order-five results prove that every nonidentity order-five
automorphism in a target fixes either 3 or 8 vertices. Let
`H = C_5^2`. An `H`-orbit on 43 vertices has size 1, 5, or 25. Write `a`
for the number of global fixed vertices, `b_L` for the number of size-five
orbits whose stabilizer is the projective line `L<=H`, and `c` for the
number of regular orbits.

For nonzero `h in L`, the number of fixed points is

```text
a + 5 b_L in {3,8}.
```

There are six lines in `H`. Combining these conditions with

```text
43 = a + 5 sum_L b_L + 25c
```

forces `a=3`, `c=1`, and exactly three distinct lines with `b_L=1`; all
other `b_L` vanish. Thus the orbit sizes are uniquely

```text
1, 1, 1, 5, 5, 5, 25.
```

The action of `GL(2,5)` on the six projective lines is transitive on their
20 unordered triples, so there is only one such `H`-set up to equivalence.
The checked-in action uses quotient kernels generated by `(0,1)`, `(1,0)`,
and `(1,1)`, together with one regular orbit.

## Exact invariant-coloring obstruction

The forced action has 51 orbits on unordered vertex pairs, with size
distribution

```text
orbit size 1:   3
orbit size 5:  15
orbit size 25: 33.
```

One Boolean variable records the color of each pair-orbit. For every one of
the `C(43,5)=962,598` vertex five-sets, two clauses require both colors among
its distinct pair-orbit variables. Deduplication gives a deterministic CNF:

```text
variables: 51
clauses:   52,362
SHA-256:   ffb03c6ae916ee712a94a66f5cbbfc85d86ae08e19e4476a6e8c504e2505561f
```

Kissat 4.0.4 returned UNSAT during preprocessing. drat-trim verified the
source trace and five successive retained cores. The final ASCII RUP trace
has 404 lines: 172 additions and 232 deletion hints. Its 6,890 bytes
compress to the checked-in 1,456-byte xz stream; drat-trim verifies it with
`-U`, which rejects RAT-only additions.

The Python generator constructs pair-orbits by least images under all 25
translations. An independent C++20 verifier builds them with disjoint-set
unions, reconstructs all Ramsey clauses with nested loops, parses the
generated DIMACS, and requires exact clause-set equality.

## Excluding order 25

An order-25 permutation on 43 points has exactly one 25-cycle, along with
cycles of lengths 1 and 5. Its fifth power is an order-five element with
exactly five 5-cycles: the 25-cycle splits into five, while every original
5-cycle becomes fixed pointwise. But the sibling classification permits
only seven or eight 5-cycles for an order-five element. Hence no order-25
element exists.

If 25 divided `|Aut(G)|`, a Sylow 5-subgroup would contain a subgroup of
order 25, isomorphic either to `C_25` or `C_5^2`. Both cases are excluded,
proving the divisibility claim.

## Reproduction

Requirements are CPython 3.11 or later, a C++20 compiler, xz, and
[drat-trim commit `2e3b2dc`](https://github.com/marijnheule/drat-trim/commit/2e3b2dc0ecf938addbd779d42877b6ed69d9a985).
No Python package is required.

```bash
DRAT_TRIM=/path/to/drat-trim ./verify.sh
```

The script rebuilds and byte-compares the manifest, independently checks the
group-action classification, regenerates the CNF, reconstructs its complete
clause set in C++, and streams the proof to drat-trim in RUP-only mode. The
final verdict must be `s VERIFIED`. Full hashes and clause distributions are
in `result.json`.

The verifier is also tested with AddressSanitizer and UndefinedBehaviorSanitizer.
Proof regeneration used
[Kissat commit `8af8e56`](https://github.com/arminbiere/kissat/commit/8af8e56f174b778aef3aa45af9f739b2a5f492c2).

`2d185ea775f2c7c16d33a235ef852d2b69f0f3c8b437335b966b4a5aa6265b45`;
the drat-trim binary SHA-256 is

## Scope, provenance, and trust boundary

The group classification depends on the three certified order-five sibling
artifacts, which exclude six of the eight possible cycle types. The exact
CNF excludes the unique surviving `C_5^2` action. The conclusion does not
exclude a cyclic order-five automorphism of type `1^3 5^8` or `1^8 5^7`,
and it does not constrain asymmetric colorings.

The mathematical inputs are elementary finite-group action theory and the
order-five classification. The computational trust boundary comprises the
independent Python/C++ orbit and formula reconstructions, exact runtime and
compiler semantics, xz, the checked-in proof bytes, and pinned drat-trim.
Kissat's exit code is not trusted without proof replay.

The inspected structured-construction literature and refreshed Discovery
Net graph did not state this `C_5^2` obstruction. Novelty is claimed only
relative to those searched sources, not as a universal priority claim.
