# Independent review of the 241-point opposed-B214 conditional core

## Verdict

**Accept, with strict conditional, relative-minimality, and imported-field
limitations.** At source commit
[`eb1263c7f9ac2b80120cd9521a6f99d2da435a7b`](https://github.com/helgithorskarp/math_results/tree/eb1263c7f9ac2b80120cd9521a6f99d2da435a7b/hadwiger_nelson_opposed241_conditional_core),
the package is a valid exact 241-point, 991-edge plane unit-distance graph.
It is four-chromatic and the complete Golomb coloring `0121212203` does not
extend to it. All 231 supplied private-vertex deletion words are valid, so
the stated relative vertex minimality follows for induced subsets that retain
the ten fixed Golomb input vertices.

This is not a five-chromatic graph, a record candidate, a global minimum
core, or a complete input-relation computation. In particular, it does not
improve the supported 509-point record.

## Independent checks and sharpenings

[`verify.py`](verify.py) imports no target code. It rebuilds the geometry in
the full eight-term multiquadratic basis generated by `sqrt(3)`, `sqrt(5)`,
and `sqrt(11)`, rather than using the target's expanded four-coefficient norm.
It decides the conditional contradiction with direct DSATUR assignments,
without the target's singleton-domain propagation. The independent search
closes after 82,989 nodes.

The review reproduces every point and edge, the 95 canonical complete Golomb
inputs, the forbidden and surviving inputs, all positive coloring witnesses,
the 121/176/56 piece counts, the 47 private contacts, the strict left-input
projection loss, and the 137 native Parts373 overlaps. The exact stream
hashes match:

- points: `70c14dfaec7875038c0f3cc1b9f84f5469143f5227fbd49377340bb46e27d908`;
- edges: `02e1fbb4c9f94cc5aca57945657706088e25560d3ca0c00217d0d17d647f55ab`;
- conditional CNF: `447be6431a55ee2a8edef34593d6718a029dadb4e1238b2799948ea05204c303`.

Two additional exact conclusions sharpen the source:

1. The graph has vertex connectivity exactly four. Exhaustive Tarjan tests
   cover all 28,920 removed pairs and, through the articulation sets of the
   pair-deleted graphs, all 2,303,960 possible triples. None separates. The
   neighbours `[17,43,59,95]` of degree-four vertex 37 give a four-cut.
2. Of the 47 private contacts, 43 are conditionally critical: deleting that
   single edge admits `0121212203`. Four are individually redundant for this
   fixed conditional obstruction: `(66,191)`, `(74,186)`, `(97,186)`, and
   `(97,226)`. Thus the core is not conditionally edge-minimal, although all
   47 contacts are necessary as a set in the weaker sense stated by the
   source.

Here “redundant” concerns only extension of this one prescribed input after
deleting one edge. It makes no claim about ordinary chromatic criticality or
simultaneous deletion of several contacts.

## Reproduce

From the repository root, using CPython 3.11 or later and only the standard
library:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 \
  hadwiger_nelson_opposed241_conditional_core_review1/verify.py \
  --check-expected

PYTHONDONTWRITEBYTECODE=1 python3 \
  hadwiger_nelson_opposed241_conditional_core_review1/controls.py

cd hadwiger_nelson_opposed241_conditional_core_review1
sha256sum -c SHA256SUMS
```

The full independent run takes about 90 seconds on the review host. The 47
edge-deletion searches account for most of this time. The controls compare
the search against brute force on 3,072 small pinned-graph instances, check
625 expanded norms, check all 512 basis associativity triples, exercise cut
logic, and reject two malformed witnesses.
