The precise application is: if an ordinary comparator word C of length 18 sorts every Boolean row of the ten-wire set K in fixture.json, then the graph formed by any suffix of C has only interval components in channels 0..9. This is conditional on the existence of such C and covers every possible comparator ordering and depth.

We use the published Theorem 2 in Codish, Cruz-Filipe, Ehlers, Mueller and Schneider-Kamp, [Sorting Networks: to the End and Back Again](https://arxiv.org/html/1507.01428#S3.SS1). In a nonredundant ordinary sorting network, the endpoints of a comparator are in the same component or adjacent components of the later suffix graph. Consequently every suffix component is a set of consecutive channels. Put each comparator in an individual layer to apply the theorem to an arbitrary sequential word. The same-component option is explicit in the 2015 version; it must not be removed when turning the theorem into an automaton.

First consider any number n of inputs and any rigorously known comparison lower bound L for ordinary sorting networks on n inputs. Let G be a generalized prefix, with oriented comparators and fixed wire permutations, and C an ordinary suffix with no intervening wire permutation. Suppose G;C sorts all Boolean inputs and has exactly L comparators.

Normalize from the input with a permutation pi assigning to each actual wire its standard-wire label. Initially pi is identity. For an oriented comparator whose minimum output is at actual a and maximum output is at actual b, emit the ordinary comparator on the unordered labels {pi(a),pi(b)}, then assign the smaller label to a and the larger label to b. A fixed wire permutation transports the labels. After every step, the actual value at a wire is the standard value read through its current label: this follows directly from the two minimum and maximum outputs of a comparator, and from a permutation merely reordering values.

The final frame must be identity. The normalized network is ordinary, so every globally sorted Boolean input is fixed by it. The actual network also returns that input sorted. The final frame must therefore fix all sorted Boolean threshold vectors, which distinguish every channel and force identity. It follows that the normalized full network sorts all Boolean inputs and has L comparators. If any normalized comparator were redundant, deleting it would give an ordinary sorter with fewer than L comparators, contradicting the imported lower bound. The published terminal-block theorem applies to the normalized full network.

Now transfer the conclusion through C by reverse induction. At its right end, both suffix graphs have singleton components and the frame is identity. Suppose that just after a current actual comparator(a,b), the actual and normalized later suffix graphs have the same interval components and the current frame pi permutes each component internally. The current normalized comparator joins pi(a) and pi(b). Those labels lie in the same respective components as a and b. If the components differ, they must be adjacent by the published theorem; if they agree, neither graph changes its components. Adding the current comparator to both graphs therefore merges exactly the same adjacent intervals. The frame immediately before this comparator differs from pi only by possibly exchanging the labels at a and b. That exchange lies within the newly merged component, so the earlier frame also permutes every new component internally. This proves the induction, including the same-component case. The fixed prefix permutation is wholly to the left of this induction and need not be identity.

For the fixture, G consists of its 14 oriented prefix comparators, the specified output order, then (3,10),(6,9),(9,10). It has 17 comparators. Exhaustive Boolean checks show channel 10 is the global maximum and that the lower ten channels have exactly the 127 rows K. If C sorts those rows, G;C sorts all 2048 Boolean inputs on eleven channels and thus every input by the zero-one principle. Its comparator count is 17+18=35, equal to the known lower bound in [Harder](https://arxiv.org/abs/2012.04400). The argument above applies. Actual channel 10 is unused by C and remains a singleton, so omitting it gives interval components on the actual K channels 0..9.

Encode a suffix partition by a Boolean cut at each boundary k between k and k+1. At the empty suffix all nine cuts are true. For a backward comparator (a,b), count currently true cuts at boundaries a through b-1. Zero means both endpoints are in the same interval. One means their two intervals are adjacent, and that cut is erased. Two or more means nonadjacent components and is forbidden. This recurrence is both necessary and sufficient for the graph components to remain intervals at each backward step. It does not forbid cycles or impose a binary tree. Its logical encoding and all 23040 one-step cases are independently audited.

The lower-bound hypothesis is essential for this transfer from a generalized prefix. On three channels, sort with (0,1),(1,2),(0,1), reverse channels 0 and 2, then append (0,2). The resulting generalized network has four comparators and sorts all eight Boolean inputs. Its final actual suffix component is {0,2}, which is not an interval. The normalized final comparator is redundant. Since the minimum on three channels is three, this violates no hypothesis of the preceding result. check.py verifies this negative control and all minimum-size three-channel factorizations.

The conclusion is a structural restriction on K18, not a proof that K18 is impossible. All thirteen-input numerical bounds stated in README.md are inherited context and remain unresolved.
