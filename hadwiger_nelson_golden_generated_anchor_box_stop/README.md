# One generated-anchor golden network stops at four colours

The frozen reciprocal-scale conversion of Parts's 16-point `{1,phi}` carrier
has **462 distinct exact plane points and 1,532 complete unit edges**. Its
literal proper four-colouring retires this architecture. We do not claim an
exact chromatic number, a five-chromatic graph, or a record improvement.

This is one whole network, not a search over copy placements. It consists of
the original carrier and 162 whole copies at scale `1/phi`, joined through
shared faces. Of these, 161 use points generated by preceding copies. The
terminal copy supplies a unique physical corner and meets the fixed base in
no point. The final graph has 406 points outside the previously four-coloured
base-anchored reciprocal overlay, so the earlier containment theorem alone
does not decide this graph.

The four-word restricts to `0213102001131001` on the original 16 source
labels. It violates twelve of the source's twenty-eight golden-distance
inequalities. Thus the source's five-chromatic **two-distance** obstruction
does not lift to this strict unit-distance construction.

## Exact frozen geometry and cap

Let `zeta=exp(2*pi*i/5)`, `q=1/abs(1-zeta)`, `b=5*zeta^4`, and
`d_j=zeta^j-zeta^4` for `j=0,1,2,3`. Physical coordinates are `q` times the
complex expressions below. The base is

```
B = { b + sum(e_j*d_j) : e in {0,1}^4 }.
lambda = d_0/d_1 = -zeta-zeta^3,  abs(lambda)=1/phi.
C_k = b + lambda*(sum(k_j*d_j) + B-b).
k in {0,1,2}^3 x {0,1,2,3,4,5}.
```

The union of these 162 copies is exactly the grid

```
G = { b + lambda*sum(n_j*d_j) :
      n in {0,1,2,3}^3 x {0,1,2,3,4,5,6} }.
```

The four vectors `d_j` are independent over the rationals (their coefficient
matrix is the identity plus the all-ones matrix, with determinant five).
Consequently `G` has exactly `4*4*4*7=448` distinct points. The root copy
shares two specified points with `B`, giving the cap `448+16-2=462` before
expansion or any chromatic query. Exact collision reconstruction shows these
are the only base/grid coincidences.

For nonzero `k`, decrement its first positive coordinate to obtain a preceding
copy. It shares eight points with `C_k`, at least two outside the fixed base.
The terminal address `(3,3,3,6)` occurs only in copy `(2,2,2,5)`; that copy is
geometrically necessary for this declared union. This is not a claim that it
is chromatically necessary.

See [PROOF.md](PROOF.md) for the source, closed-overlay distinction and exact
all-pairs certificate semantics. [ARCHITECTURE.json](ARCHITECTURE.json) was
frozen before point expansion and the ordinary colour query.

## Reproduce

Python 3.11+ and its standard library suffice to verify every mathematical
claim. From this directory:

```bash
python3 -B verify.py
python3 -O -B verify.py
python3 -B reproduce.py --output /tmp/hn-golden-generated-replay
sha256sum -c SHA256SUMS
```

The verifier imports neither the producer nor another package's executable.
It uses nested real quadratic arithmetic, reconstructs all 106,491 final
pairs, checks the colour word directly, and rejects ten corrupted witnesses.
It also reconstructs the finite registered base overlay solely to check
noncontainment; it does not colour or vary any new network.

Optional regeneration of the same SAT word uses `python-sat==1.8.dev24` with
CaDiCaL 1.9.5:

```bash
python3 -B reproduce.py --output /tmp/hn-golden-generated-sat --solve
```

The exact-one colour encoding has four Boolean variables per vertex. A
positive satisfying word is decoded and checked against the complete edge
list. The solver is not in the final proof's trust boundary. The replay
produced identical coordinate bytes, edge bytes and colour word.
