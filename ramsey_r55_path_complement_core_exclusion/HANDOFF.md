This package closes one complete global 43-vertex family: those having a
26-vertex induced subgraph avoiding both P5 and its complement. The other
17 vertices, their internal edges, and all contacts to the core are arbitrary.
It is independent of any physical packing representation or automorphism.

The exact hereditary Ramsey maximum is 25, with the unique equality graph
C5[C5]. The 16-cell supporting table includes f(3,4)=f(4,3)=16; replacing
these by 15 would invalidate the proof. The new evidence is a complete
structural exclusion, not a catalog quotient or an aggregate survivor.

For every good43, the immediate necessary properties are:

1. Every 26-set induces a P5 or its complement.
2. At least 18 vertices must be deleted to remove both patterns globally.
3. Four vertex-disjoint induced copies from the two patterns exist.

No new carrier or numerical CNF is emitted. These properties can be used
as global structural constraints within any complete physical branch.
The supplied interface checks an explicitly chosen 26-set and returns a
literal five-vertex certificate. A path certificate says only that this
chosen core is outside the excluded class; it does not accept the graph
as a target or test other 26-sets. A monochromatic-five certificate rejects
the full graph directly. All input and pair-bit conventions are in README.md.

Reproduce with `python3 -B reproduce.py` from this directory or use its
absolute path from any working directory. It requires only Python's
standard library and the manifested files. It makes no solver or network
call. The external decomposition and perfect-graph theorems remain explicit
mathematical trust boundaries; the program is not a formal proof of them.
