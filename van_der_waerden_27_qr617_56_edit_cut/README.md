# QR-617 color-budget rigidity and a 56-change construction cut

**six-vdw-2, researcher.** Any binary coloring of `[1,3704]` avoiding all
monochromatic nonconstant seven-term arithmetic progressions must differ
from the prescribed QR-617 prefix at **at least 56 of its 3696 nonzero
positions**, including **at least 27 of each original color class**.
By complementation the total is at most 3640 and each class at most 1821.
The seven old pole values and the new endpoint are unrestricted. No
periodicity or symmetry is imposed on the candidate coloring.

The prefix alone is rigid through 54 changes; the final 55-change exclusion
uses 12 endpoint/root branches. See [PROOF.md](PROOF.md) for precise
quantifiers, the induction, and scope. This is an exact neighborhood
exclusion and a useful cardinality cut for constructing a witness. It does
not improve the known lower bound for the symmetric two-color/seven-term
number `W(2,7)`, and does not prove a global upper bound.

## Reproduce

Python **3.11+**, standard library only, one process and thread. From this
directory:

```sh
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1
python3 generate.py --output build
python3 verify.py build
python3 checker_controls.py build
```

The generator writes three prefix transcripts and 12 conditional transcripts
to ignored `build/`, plus a manifest. The complete generation takes a few
minutes on one CPU and uses under 100 MiB in the measured run. The default
90-second limit applies to each case. A stall or limit raises an error and
establishes no mathematical exclusion.

The checker independently validates AP coordinates, modular colors, every
antecedent, disjointness, the final contradiction, and complete case coverage.
It also compares generated bytes and statistics with [expected.json](expected.json).
Its compact expected fields are:

```json
{
  "verified": true,
  "required_nonzero_changes": 56,
  "maximum_nonzero_changes": 3640,
  "required_changes_per_original_color": [27, 27],
  "maximum_changes_per_original_color": [1821, 1821],
  "prefix_rigidity_through_total_changes": 54,
  "checked_nonempty_cardinality_pairs": 1595
}
```

Nine deliberately corrupted proof or coverage controls must be rejected.
The checker is separately implemented by the same author; no independent
human review or formal proof claim is implied. Generated transcripts total
about 2.46 MB and are omitted from Git. Source and a compact hash/result
manifest suffice to regenerate and check all evidence, with no downloads,
solver, omitted input, or external dependency.

The checked run took 163.323 seconds to generate and 2.246 seconds to verify;
generator peak RSS was 93336 KiB. [validation.json](validation.json) records
the environment, resource measurements, and checks performed.

For a second byte-for-byte reproduction:

```sh
python3 generate.py --output build/second

```
