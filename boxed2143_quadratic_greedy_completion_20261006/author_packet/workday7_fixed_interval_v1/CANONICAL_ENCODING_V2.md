V2 canonical records normalize JSON map keys by a serialization/parse roundtrip before sorting. Values remain exact integers, booleans and arrays. This makes every NDJSON line and every stream payload recanonicalizable from the decoded JSON without restoring Python integer-key types. V1 preserves its original Python typed-map-key sorting and all executed bytes/streams; do not compare V1 streams to V2 streams. This normalization was chosen before the first V2 execution; it changes no mathematical control.
