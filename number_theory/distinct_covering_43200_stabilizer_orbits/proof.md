# A 324-case completion reduction at period 43200

Actual author **six-covering-3**, role **researcher**. This is an
author-checked structural lemma with a standalone exact checker;
independent review and formalization are pending. The construction applies
known CRT/residue-tree automorphisms. No priority for that general method
is claimed.

Let N=43200=64*27*25. Prescribe one class at each of

    8,9,10,12,15,16,18,20,24,25,30,36,40,45,

with arbitrary phases. Write s for the prescribed 16 phase and a for the
prescribed 25 phase. Every unused eligible divisor m|N, m>=8 may be
omitted or have an arbitrary phase. The actual LCM need only divide N;
the prescribed 8 class makes the minimum exactly 8.

**Conditional reduction.** Complete the two missing moduli 48 and 50.
Their 2400 raw phase pairs have exactly **324 orbits under the subgroup
declared below**: 27 at 48 and 12 at 50, with independent choices. The
prescribed fourteen-class parent has a covering completion if and only
if one of these representative sixteen-class prefixes has a completion.
The same equivalence holds with a specified actual LCM dividing N.
This does not assert maximality of the subgroup or impossibility of any
representative.

**Further splits.** After an arbitrary prescribed 48 class, the missing
50 split has 12 representatives. After additionally prescribing b modulo
50, the missing 75 split has 21 representatives if a and b mod25 differ,
or 18 if they coincide. These equivalences also preserve actual LCM.

## Seven binary sibling flips

For each r=0,...,7 define sigma_r on physical residues modulo N by adding
16200 when x=r(mod16), subtracting 16200 when x=r+8(mod16), and fixing
all other x. The shift is 8 modulo 64 and 0 modulo 675. Thus sigma_r
interchanges the fourth binary digit below the root r, fixes all other
binary digits, and fixes both odd-prime CRT coordinates. It is an
involution.

Every divisor of N with binary valuation at most 3 divides 16200, so
each of its congruence classes is fixed. A divisor with binary valuation
at least 4 determines x mod16, so sigma_r acts on its whole class by one
constant translation. Therefore sigma_r maps every divisor class onto
one class of the same modulus. The inverse and equal class cardinalities
give equality of the image class, rather than mere containment.

Let G2(s) be generated by the seven sigma_r with r different from s mod8.
The root containing the prescribed 16 class is untouched. All other
prescribed moduli have binary valuation at most 3, so every prescribed
class is fixed. These seven independent involutions have disjoint
supports and generate the full independent sibling swaps at those roots.

Among the 16 binary leaves there are nine orbits: the two untouched
leaves under s mod8 and one two-element orbit under each other root.
A 48 phase also specifies its ternary coordinate, which is fixed by
G2(s). Consequently there are 3*9=27 phase orbits. An explicit
representative for a raw phase c is obtained by retaining c mod3 and
replacing c mod16 by its root c mod8, except that both leaves below
s mod8 are retained. The unique phase modulo 48 with these coordinates
is the representative. A nonidentity transporter is sigma_(c mod8).

Each sigma_r fixes every 50 and every 75 phase because both moduli
divide 16200. No restriction on the prescribed 16 phase is needed.

## Quinary leaf permutations

Use CRT coordinates modulo 1728 and 25. Write the 25 coordinate as r+5j,
0<=r,j<5. Fix the 1728 coordinate and every root label r. Independently
permute the five second-digit labels below each root, fixing the
prescribed leaf a under its root. Denote this group by G5(a).

Every divisor class of N has a cofactor condition in 1728 and either no
quinary condition, a root condition modulo 5, or a complete leaf condition
modulo 25. The action maps it to a class of the same modulus. Among the
fourteen prescribed moduli, only 25 has quinary valuation 2, so every
prescribed class is fixed. An additional 48 class is fixed pointwise.

There is one leaf orbit below each of the four roots other than a mod5.
The selected root has two orbits: the singleton a and its four other
leaves. Thus there are six leaf orbits. A 50 phase also specifies parity,
which is fixed by the 1728 coordinate, giving 2*6=12 phase orbits.

For a raw 50 phase b, retain its parity. If b mod5 differs from a mod5,
choose the leaf b mod5. If b mod25=a, choose a. Otherwise choose the
least leaf below that root different from a. The unique 50 phase with
this leaf and the retained parity is the representative. For a=3 these
representatives are

    {0,1,2,3,4,8,25,26,27,28,29,33}.

An explicit transporter swaps the raw leaf u=b mod25 with its target v.
They have the same root. With H=N/25, set

    delta = H*((v-u)*H^(-1) mod25).

Add delta on leaf u, subtract it on leaf v, and fix all other leaves.
This fixes the 1728 coordinate, performs exactly that leaf transposition,
and fixes a. The inverse exists since gcd(H,25)=1. The same formula at
Q=3600 commutes with projection from N; both periods are checked literally.

After additionally prescribing b modulo 50, fix F={a,b mod25}. If these
leaves are distinct, there are seven leaf orbits, hence 21 phase orbits
at missing 75=3*25. If they coincide, there are six leaf orbits and 18
phases. This remains valid after every 48 phase. A transporter fixes
both pinned leaves and the ternary coordinate. For a=3, b=33, the 21
representatives are

    {0,1,2,3,4,8,13,25,26,27,28,29,33,38,50,51,52,53,54,58,63}.

This supplies another completion equivalence when the 50 split leaves a
question unresolved. It asserts no exclusion of these children.

## General pinned-digit count

For clarity, both constructions are special cases of the following
elementary CRT/tree action. Let N=p^e M, gcd(p,M)=1, and 1<=k<=e. A leaf
is a residue modulo p^k; its root is its residue modulo p^(k-1).
Independently permute the kth digit under each root, fixing a set F of
leaves. Fix all lower and higher p-adic digits and the M coordinate.
Write f_r for the number of leaves of F below root r.

Every prescribed class with p-valuation below k is fixed automatically.
Require every prescribed class with p-valuation at least k to have its
p^k leaf in F; then it too is fixed. For an unused modulus d*p^t with
d|M and k<=t<=e, the declared subgroup has exactly

    d * p^(t-k) * sum_r (f_r + indicator(f_r<p))

phase orbits. Indeed the d coordinate and the t-k higher digits are
fixed. Every pinned leaf forms a singleton orbit; the unpinned leaves
below a root form one further orbit precisely when any remain.
The product of these independent choices proves the count.

These maps preserve every divisor partition: a p^t class with t<k
fixes only unaffected digits; a class with t>=k fixes its kth digit and
is mapped to one whole class at the same p^t. CRT combines this with
the fixed cofactor. Binary e=6,k=4,t=4,d=3 and one pinned leaf give
27. Quinary e=k=t=2,d=2 and one pin give 12. Two distinct quinary pins
with d=3 give 21, whether they share a root or lie in different roots.
Coincident pins give 18. This count refers to the declared subgroup,
not to the largest stabilizer of any particular parent.

## Product and covering equivalence

G2(s) changes only the binary CRT coordinate, while G5(a) changes only
the quinary coordinate. Their actions commute and have trivial
intersection. G2(s) fixes every 50 phase, and G5(a) fixes every 48 phase.
The phase-pair orbits of their direct product are therefore exactly the
Cartesian products of the 27 and 12 single-modulus orbits: 324.

If a hypothetical parent completion omits 48 or 50, adjoin any class at
the missing modulus. These are unused eligible divisors, so coverage and
distinctness persist. The prescribed anchors have LCM 3600, which is
divisible by 48, 50 and 75. These additions therefore preserve the
original actual LCM. Transport the whole covering to a representative
pair by the commuting maps. Every used modulus, exact minimum and
actual LCM is preserved, and every unused phase remains free. This
proves the forward implication. A completion of a representative prefix
is itself a parent completion, giving the reverse implication.
The same argument proves the subsequent single 50 and pinned 75 splits.

Consequently these equivalences hold with a specified actual LCM L
dividing N; any parent completion necessarily has 3600|L. In a different
application of the general pinned-digit lemma, adjoining an extra
divisor preserves actual LCM when it already divides that LCM.
Otherwise ambient-divisor existence and prescribed actual LCM must
be distinguished. No numerical bound on L_min(8) follows from this lemma.

the Python standard library. It constructs physical CRT lookup maps
using ordinary remainders, compares all 58 generators pointwise, checks
all 84 divisor partitions, involutions, projection and commutation,
and checks all 2400 raw pairs for every one of the 16 possible known
16 phases and 25 possible known 25 phases. It also checks all 75 phases
for all 1250 known 25/50 pairs, with full physical-class checks for the
displayed two-pin example. Expected fields and event hashes appear in
[expected.json](expected.json). The general formula is justified by the
written orbit argument; the checker verifies its stated applications.
