# Endpoint-dependent QR-617 repair cuts

**six-vdw-2, researcher.** For any binary coloring of `[1,3704]` avoiding
monochromatic nonconstant seven-term arithmetic progressions, the new
endpoint color determines a necessary edit budget relative to the fixed
QR-617 prefix:

| New endpoint color | Required original-class changes | Required original-class retentions |
|---|---|---|
| 0 | At least 28 in original color 0 | At least 28 in original color 1 |
| 1 | At least 28 in original color 1 | At least 28 in original color 0 |

Each original class has 1848 prescribed positions; all seven old pole values
and the endpoint are free. The opposite class is unrestricted in the
lower-bound certificates. No periodicity or candidate symmetry is assumed.
See [PROOF.md](PROOF.md) for exact coordinates, quantifiers and the induction.

This adds constraints beyond the
[previous 56-change cut](https://github.com/helgithorskarp/math_results/tree/main/van_der_waerden_27_qr617_56_edit_cut),
without a larger total-distance bound. No length-3704 witness or new van der
Waerden lower bound is supplied.

Python **3.11+**, standard library only. From this directory run sequentially:

```sh
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1
python3 generate.py --output build
python3 verify.py build
python3 checker_controls.py build
```

The generator writes 12 transcripts to ignored `build/`; complete generation
takes a few minutes on one CPU. A 90-second limit applies to each branch.
A stall or time limit raises an error and yields no mathematical exclusion.
The checker validates every AP and proof step independently of the generator,
then requires all six covering roots for each endpoint color and the full
1848-point opposite-class cap. Generated bytes and counts must match
[expected.json](expected.json). Nine corrupt proof or coverage controls must
be rejected. Compact expected fields are:

```json
{
  "verified": true,
  "minimum_changes_in_original_endpoint_color_class": 28,
  "maximum_changes_in_original_opposite_color_class": 1820,
  "unrestricted_other_class_size": 1848,
  "prescribed_nonzero_positions": 3696,
  "exceptional_prefix_positions_free": 7,
  "new_endpoint_free": true
}
```

The generator/checker reuse the earlier square/bitset and Euler/set code,
respectively. This is same-author independent checking, not independent
human review or formalization. Source is self-contained. The 1899001-byte
transcript corpus is omitted from Git and requires no omitted external input.
[validation.json](validation.json) records the checked run and resources.
Generation took 134.55 seconds with peak RSS 92016 KiB; full checking took
2.224 seconds on the measured run.

For a second exact reproduction, run `python3 generate.py --output build/second`
and `python3 verify.py build/second`. Every certificate has a deterministic
SHA256 digest in the published manifest. Hashes do not replace proof checking.
