# The complete sqrt(5) lens layer leaves the opposed-B214 relation unchanged

Start with the independently reviewed 343-point, 1,782-edge opposed-B214
support `S343`, whose complete normalized Golomb four-colour relation has 66
patterns rather than the bare source's 95.  For every pair of points of `S343`
at squared distance `16/9`, adjoin both intersections of their unit circles.
The resulting complete strict plane unit-distance graph has **451 distinct
points and 2,170 edges**, but all 66 source patterns still extend.  Its
chromatic number is exactly four.

This is the exact stopping boundary for one predeclared finishing class.  It
does not produce a five-chromatic graph or improve the 509-point record.  The
unchanged complete-input relation banks `S343`; no other distance class,
one-sided layer, phase, receiver, or second completion is searched here.

## Why this class was selected

Every `S343` point lies in the field generated by `sqrt(3)` and `sqrt(11)` in
the reviewed coordinate frame.  A point with unit contacts to three
noncollinear old points is recovered by two linear radical-axis equations and
therefore remains in that old field, where a known four-colouring is already
available.  A useful fresh finisher consequently needs outside-field points
with at most two old contacts, coupled by genuine new--new edges.

Squared distance `16/9` gives the especially simple unit-circle intersections

```text
m +/- (sqrt(5)/4) R(q-p),
```

where `m=(p+q)/2` and `R` is a quarter-turn.  The `sqrt(5)` coefficient leaves
the old field.  Exact preflight finds 54 old centre pairs, hence exactly 108
new points—comfortably within the 165-point finishing allowance.  Complete
reconstruction then gives 216 old--new edges and 172 new--new edges.  Every
new point has exactly two old contacts but total degree four through seven;
the whole graph has neither an articulation vertex nor a bridge.  Thus the
test is not neutral merely because it decomposes at a point or edge.

## Exact result

Coordinates use common denominator 144 in the ordered basis

```text
1, sqrt(3), sqrt(5), sqrt(15), sqrt(11), sqrt(33), sqrt(55), sqrt(165).
```

The three square classes 3, 5, and 11 are independent, so coefficientwise
equality is exact.  The checker reconstructs all 101,475 unordered physical
pairs and obtains:

| Quantity | Exact value |
|---|---:|
| Old points / edges | 343 / 1,782 |
| Squared-distance-`16/9` centre pairs | 54 |
| New outside-field points | 108 |
| Old--new / new--new edges | 216 / 172 |
| Complete points / edges | 451 / 2,170 |
| Articulation vertices / bridges | 0 / 0 |

The reviewed source certificate and its 1,382-lemma RUP proof are hash-pinned
and replayed.  They exclude the other 29 normalized Golomb patterns.  For
each of the source's 66 surviving patterns, `certificate.json` contains a
literal proper four-colour word on all 451 points with that exact ten-vertex
projection.  Hence the final relation is exactly the same 66 patterns.  Since
the graph contains the four-chromatic Golomb subgraph, its chromatic number is
exactly four.

## Reproduce

From the repository root, using CPython 3.11 or later and only the standard
library:

```sh
python3 -B hadwiger_nelson_opposed343_sqrt5_lens_stop/verify.py --check-expected
python3 -O -B hadwiger_nelson_opposed343_sqrt5_lens_stop/verify.py --check-expected
python3 -B hadwiger_nelson_opposed343_sqrt5_lens_stop/controls.py
python3 -O -B hadwiger_nelson_opposed343_sqrt5_lens_stop/controls.py
(cd hadwiger_nelson_opposed343_sqrt5_lens_stop && sha256sum -c SHA256SUMS)
```

The controls independently implement multiquadratic multiplication by
square-class bit masks, rescan all 101,475 point pairs, recover all 2,170 edges
entry-for-entry, test cut detection on hand-checkable graphs, and reject an
improper colour word and nonintegral coordinate division.

Optional byte-for-byte regeneration of the positive words uses
`python-sat==1.9.dev15` and CaDiCaL 1.9.5:

```sh
python3 -m venv /tmp/opposed343-lens-venv
/tmp/opposed343-lens-venv/bin/pip install -r \
  hadwiger_nelson_opposed343_sqrt5_lens_stop/requirements-discovery.txt
/tmp/opposed343-lens-venv/bin/python -B \
  hadwiger_nelson_opposed343_sqrt5_lens_stop/produce_certificate.py \
  /tmp/opposed343-lens-certificate.json
cmp hadwiger_nelson_opposed343_sqrt5_lens_stop/certificate.json \
  /tmp/opposed343-lens-certificate.json
```

The SAT solver is only a positive-witness producer.  The standard-library
verifier checks every digit against every exact edge and does not trust a SAT
or UNSAT verdict.
