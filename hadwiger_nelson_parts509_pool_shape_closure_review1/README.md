## Proof audit

Let a minimum blocking set be `X subset S union Q5`.  Inclusion minimality
forces minimum degree at least four: otherwise a proper four-colouring after
removing a low-degree vertex extends greedily.  If `a=|X intersect Q5|` and
`d=|S minus X|`, then `|X|<=134` implies `d>=a+1`.  Adding back exactly
`d-a-1` omitted `S`-vertices preserves non-four-colourability and yields the
normal form “delete `a+1`, add `a`.”  Conversely every such set has size 134.
This proves the shape equivalence without computation.

For a fixed `a`, a Boolean `r_v` says that `v` is removed from `S`, and `q_w`
says that `w` is added from `Q5`.  For a killing set `D`, the candidate
`(S minus R) union A` meets `D` exactly when

```text
OR(-r_v for v in D intersect S, q_w for w in D intersect Q5)
```

holds.  The two cardinality equations are `sum r_v=a+1` and `sum q_w=a`.
Every blocking candidate must meet every certified killing set because each
killing-set complement has an explicit four-colouring.  Unsatisfiability of
the master therefore excludes every blocking candidate of that shape.

## Trust boundary and uncertainty

The six exclusions trust the exact coordinate inputs, the completeness of
the 20-class interface lemma, CPython/SymPy integer and rational semantics,
CaDiCaL as proof producer, and `drat-trim` as proof checker.  The alternate
masters replace the target cardinality encoder but still trust PySAT and a SAT
solver; their role is independent corroboration, while the DRAT checks carry
the proof-producing computation.

The definition of `Q5` is imported from the committed completion-point
enumeration.  The 20 interface witnesses were replayed, but completeness of
the 20 interface classes was not re-proved.  As noted above, the 45-case range
imports the solver-trusted `h_S>=90` result.  The later all-anchored
four-point closure subsumes the target's `a=4` case; `a=5` remains a genuine
additional restricted-pool exclusion.  Residual uncertainty lies in these
explicit dependencies, not in the regenerated six master refutations.
