# A dominating triple containing an edge cannot force five colours

**Exact computer-assisted theorem.** Every plane unit-distance graph having
a dominating set of at most three vertices that contains an edge is
four-colourable. Equivalently, if a five-chromatic plane unit-distance graph
has domination number three, every dominating triple in it is independent.

The new geometric statement is uniform. Normalize the edge to centres (0,1)
and put the third centre at an arbitrary point (z). The strict unit-distance
graph on the three centres and their **three entire unit circles** is
four-colourable for every (z). All circle intersections, extra unit edges,
tangencies, and infinite direction orbits are included. Cases in which (z)
is adjacent to an endpoint use the independently accepted connected-triple
theorem; the proof here closes every previously open exactly-one-centre-edge
placement.

The finite computer-assisted step has 251 possible pairs of parity-conflict
graphs on at most four mixed circle intersections. Only two abstract pairs
are unsatisfiable. Both require the third centre to be

\[
z=(1\mathbin\pm i\sqrt{11})/2,
\]

where exact angle geometry shows that neither required cross conflict exists.
The two abstract one-triple exceptions would force the same centre locus, but
neither common point of the circles at (0,1) is then unit distance from
(z). Thus every physically realizable placement has a palette allocation.

This is a whole-family exclusion, not a five-chromatic construction, a global
vertex lower bound, or an improvement to the 509-vertex published record.
It does not decide independent dominating triples. It uses actual circle
geometry before accepting any abstract conflict system as a candidate.

## Reproduce

Python 3.11 or later and its standard library suffice. From this directory:

```sh
tmpdir=$(mktemp -d)
python3 -B build.py --out "$tmpdir/build"
cmp certificate.json "$tmpdir/build/certificate.json"
python3 -B verify.py > "$tmpdir/verify.json"
cmp expected.json "$tmpdir/verify.json"
python3 -O -B verify.py > "$tmpdir/verify-opt.json"
cmp expected.json "$tmpdir/verify-opt.json"
sha256sum -c SHA256SUMS
```

The producer enumerates set partitions and binary phase labels. The checker
does not enumerate those encodings: it recognizes conflict graphs as disjoint
unions of complete bipartite components, exhausts all graph masks and palette
allocations, and separately checks the exceptional geometry. It also
reconstructs three exact finite orbit patches in

\[
\mathbb Q(\sqrt2,\sqrt3,\sqrt{11})^2,
\]

including the double-exceptional placement and a triple-owned intersection.
Every physical point pair is tested for exact unit distance and every supplied
colour is checked. These patches are controls for the universal argument, not
samples from which its quantifier is inferred.

The compact certificate is generated byte for byte. No CAS, native solver,
floating-point equality, external data, omitted trace, or background
computation is used. The trust boundary is the written continuum proof,
finite exhaustive Python loops, rational multiquadratic arithmetic, and
ordinary CPython execution. The independent implementation is author-run;
external review and proof-assistant formalization are not claimed.
