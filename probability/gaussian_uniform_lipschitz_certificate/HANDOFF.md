# R2/R3/R8 handoff: a uniform strong-contraction remainder

The new input is a universal spherical comparison, not another middle cell.
For any bounded law in R^d and a prescribed L-Lipschitz image,

```
S_Y(lambda) <= d^(3/2) L S_X(lambda),   L sqrt(d)<=1, lambda>=0.
```

Independent-copy symmetrization turns `2S_X` into an averaged log cosh
moment. A radial cosh moment is bounded by the product of the d frame
moments, each at least one. Averaging frame logarithms and applying two
Jensen inequalities gives the displayed comparison. This is an analytic
inequality; no angular mesh or endpoint-vector convex order is assumed.

In dimension three, any exact pair certificate `27|dy|^2<=q^2|dx|^2`,
`0<q<1`, supplies

```
J(lambda) >= (1-q)V/(96R^2),        lambda>=1/(2R),
J(lambda)/D >= (1-q)/(192R^2),
s_* = 4224R^4/((1-q)V).
```

The accepted endpoint6032/6048 then signs **every threshold**, for every
s>=s_*. Fixing R, a positive scatter floor v and q gives one cutoff for
all bounded laws and maps satisfying those bounds. The certificate needs
no covariance inverse and has no growing replica degree or inverse-threshold
cost. A convenient whole class is Lip(T)<=1/6, s>=33792R^4/V.

This is a separation of certificate scope, not a new geometric example claim.
