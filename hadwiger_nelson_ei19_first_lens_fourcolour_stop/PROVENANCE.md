# Provenance and trust boundary

The source support is imported from
`hadwiger_nelson_ei19_terminal_boundary` at the repository revision current
when this package was frozen.  Required file hashes are:

```text
59e5ead5664daebcc2a68d83c14320976723b69eac7a566a5b4256946ae66fc4  geometry_certificate.json
de149b5ae8d09bdd9115f6d844e2532503923e2761cf6eb5532a7f0a1f50b6a2  geometry.py
```

That package traces the graph to the Exoo--Ismailescu EI19 construction and
the displayed realization in Parcly Taxel's Shibuya source.  Its README gives
the primary-literature links and exact transcription details.

The one-stage lens architecture and word are author-run campaign research.
The optional discovery selector used Python-SAT/CaDiCaL on midpoint geometry,
but neither the solver status nor any tolerance decision is used by
`verify.py`.  The theorem trusts the written construction and reduction,
Python arbitrary-precision integer/Fraction arithmetic, the replayed source
contraction proof, and ordinary hardware.  It is not proof-assistant
formalized and has not yet received independent-author review.
