# Deltoidal hexecontahedron: adaptive area reduction and a whole receiver triangle

Author: **six-rupert-1 (researcher)**, 2026-09-30.

Let `K=conv{V_0,...,V_61}` be the standard centered deltoidal
hexecontahedron, with the ordered exact coordinates generated by
[verify.py](verify.py) from
[McCooey's model](https://dmccooey.com/polyhedra/DeltoidalHexecontahedron.txt).
Let `G` be its full group of sixty proper body rotations, `P_n` the
orthogonal projection onto `n^perp`, and `A(n)=area(P_n K)` for unit `n`.
Write

```
s=sqrt(5),
M=((3s-5)/6,(s-1)/6,1), m=M/||M||,
a0=sqrt((3503950+1491850s)/31581),
J_n=2nn^T-I.
```

The [global-area parent](global_area_proof.md) establishes the exact
minimum `a0`, its sixty directed normal orbit `G.m` (thirty axes), the
complete twelve closed chamber cells, their physical area vectors, the
full proper body group and the minimum shadow. The new checker fully
replays that parent before using its data. Its old all-source receiver
caps remain valid.

The new conclusions are as follows.

1. For every unit source normal `k`,
   `dist(k,G.m)<=6(A(k)-a0)`.
2. Put `S=P_m K`. If a proper planar rotation `U` satisfies
   `US subset S+eta D`, where `D` is the unit disk and `0<=eta<=1/28`,
   reduce `U` modulo the complete planar group `C2`. Its reduced angle
   lies in `[-pi/2,pi/2]` and its rotation chord is at most `2eta`.
3. There is the following reusable receiver criterion. Let `u_z=1` in
   one of the **whole closed cells 4,7,9**, and put `n=u/||u||`. Define

   ```
   e=A(n)-a0, delta=||n-m||, a=6e,
   eta=(5/2)(a+delta), Theta=(303/50)(a+delta).
   ```

   For that cell, use the four actual weak supports in Section 4 and set
   `T_j(u)=V_j cross (E_j cross u)`. Define

   ```
   r_cell(u)=min_{||z||=1} max_j z.T_j(u).
   ```

   If

   ```
   eta<=1/28 and r_cell(u)>(25/16)||u||Theta,            (1)
   ```

   then, for **every** `Q in SO(3)`, planar translation `t`, and
   `lambda>=1`,

   ```
   lambda P_n(QK) subset P_n K+t
     iff lambda=1, t=0, Q in G union J_n G.            (2)
   ```

   These are two disjoint **left cosets**, with exactly 120 relative
   rotations, all giving equal shadows. No initial source-normal,
   full-angle, or planar-roll restriction is imposed. Antipodal normals
   and proper body images have the transported conclusions.
4. Criterion (1) holds throughout the following **whole closed triangle**
   of receiver rays, including every edge and corner:

   ```
   N7=((25-7s)/38,(9-s)/38,1),
   N8=((5-s)/10,(-5+3s)/10,1),
   U7=(19M+N7)/20, U8=(19M+N8)/20,
   T=conv{M,U7,U8}.                                   (3)
   ```

   In particular, the directed normal `U7/||U7||` is more than chord
   **1/500** from `m`. This triangle extends the parent cap in these
   directions. All its proper body images and antipodal receiver
   directions satisfy (2).

The theorem excludes every strict passage on these receiver regions.
It supplies no strict passage and leaves the complementary receiver

## 1. Global area excess controls every source normal

The parent checks `A(u/||u||)=C_i.u/||u||` on every entire closed cell,
including the boundaries. Let `u_j` be its fourteen distinct unit-z
chamber corners. The unique minimal corner is `u_9=M`. For all thirteen
other corners put

```
q_j=A(u_j/||u_j||)^2, D_j=||u_j-M||^2,
L_j=q_j-a0^2-D_j/9.
```

The new checker proves, in the ordered field `Q(s)`,

```
D_j>0, L_j>0, L_j^2>4a0^2 D_j/9.                     (4)
```

These branch checks imply
`A(u_j/||u_j||)-a0>sqrt(D_j)/3`. No undecided square-root sign or decimal
comparison is used. On a segment of the unit-z chart, the derivative of
normalization `x -> x/||x||` has operator norm `1/||x||<=1`. Hence

```
2||u_j/||u_j||-m|| <= 2sqrt(D_j)
                 <= 6(A(u_j/||u_j||)-a0).             (5)
```

The corresponding inequality at `M` has both sides zero.

For any point of any closed chamber cell, write `u=sum t_j u_j`, with
`t_j>=0`, `sum t_j=1`, and set

```
b=sum t_j||u_j||,
alpha_j=t_j||u_j||/b,
v=u/b=sum alpha_j (u_j/||u_j||), n=v/||v||.
```

The vector `v` is nonzero, since its last coordinate is `1/b`, and
`||v||<=1`. By the reverse triangle inequality,

```
||n-m|| <= ||n-v||+||v-m|| <= 2||v-m||
        <= 2 sum alpha_j||u_j/||u_j||-m||.
```

Linearity of `C_i` and positivity of the corner areas give

```
A(n)=sum alpha_j A(u_j/||u_j||)/||v||
    >= sum alpha_j A(u_j/||u_j||).
```

Combining this with (5) proves the stronger chamber estimate
`||n-m||<=6(A(n)-a0)`. Fold an arbitrary normal into the reflection
chamber. All orthogonal body symmetries preserve area, and the parent
checks that the full minimum orbit is precisely `G.m`, including its
antipodes. This proves the global estimate in conclusion 1 without an
initial source-cell assumption.

## 2. A linear bound for the complete reduced roll interval

Use any oriented orthonormal coordinates on `m^perp`. Among **all 62
original vertices**, the parent checks that only the antipodal projected
vertices `V_4,V_57` have maximum radius `R0`, where

```
R0^2=(155+65s)/58>4.
```

All other projected radii are at most `sqrt(5)`. These two distinct
maximal points force the proper planar shadow group to be exactly `C2`;
central symmetry supplies its half-turn.

The new positive-branch square checks prove

```
R0-sqrt(5)>1/28.                                     (6)
```

Suppose `US subset S+eta D` with `0<=eta<=1/28`. Reduce the rotation
angle modulo `pi` to `alpha in [-pi/2,pi/2]`. Take the support direction
along `U(P_m V_57)`. The necessary support inequality is

```
R0 <= max{R0 cos(alpha),sqrt(5)}+eta.
```

By (6) the second branch cannot supply this inequality. Therefore, with
`r=2sin(|alpha|/2)`,

```
r^2=2(1-cos(alpha))<=2eta/R0<=eta<=1/28<1/25.          (7)
```

This first step covers the **entire** reduced roll interval; small roll
is derived.

For its two signs use the actual outward support normals of edges
`(57,59)` and `(41,57)`, both supporting at `V_57`. The checker verifies
all 62 support comparisons for each edge. After normalizing the support
normal to unit length, let `h` be its support height and `tau` the
signed first derivative of `U(P_m V_57)` in that direction. Exactly,

```
h^2=(95+40s)/41 < (9/4)^2,
tau^2=(845+345s)/2378 > (3/4)^2.                       (8)
```

The first edge has `tau>0`, the second `tau<0`. Choose the edge with the
same sign as `alpha`. For `r>0`, the projected vertex support excess is

```
g=|tau|sin(|alpha|)-h(1-cos(alpha)),
g/r=|tau|sqrt(1-r^2/4)-hr/2
   > (3/4)(99/100)-(9/4)(1/10)=207/400>1/2.            (9)
```

Here (7) gives `r<1/5` and the indicated root lower bound. The inclusion
requires `g<=eta`, so `r<2eta` when `r>0`; in every case `r<=2eta`.
For `eta=0`, (7) already gives `r=0`. Thus the two edge probes prove
conclusion 2, including both signs and the remote part of the roll
interval.

## 3. Eliminate arbitrary source directions and proper rotations

Centered convex symmetry first removes translation and scale from a
necessary containment. Indeed, for centrally symmetric `A,B`,
`lambda A subset B+t` implies
`lambda h_A(z)<=h_B(z)-|t.z|` for every planar `z`. With `lambda>=1`
it follows that `A subset B`.

Set `k=Q^T n`. Area monotonicity gives `A(k)<=A(n)`. By conclusion 1,
some `h in G` has

```
||h^T k-m||<=6(A(n)-a0)=a.                            (10)
```

Replace `Q` by the proper source gauge `Qh`. Let `R_1,R_2` be the
minimal proper rotations taking `m` to `h^T k` and `n`, respectively.
Their rotation chords are at most `a` and exactly `delta`. The gate
`eta<=1/28` implies `a+delta<=1/70`, so these transports are unique.

Let `B0` have an oriented pair of orthonormal rows spanning `m^perp`.
The receiver frame is `B2=B0 R_2^T`. There is `U in SO(2)` with

```
B2 Qh=U B0 R_1^T.
```

The body radius is strictly less than `5/2`, as rechecked by the parent.
Every vertex displacement under a minimal normal transport is at most
this radius times its chord. This bounds the Hausdorff displacement of
the **full** shadows, not merely selected contacts. The centered
containment therefore implies

```
US subset S+eta D, eta=(5/2)(a+delta).                 (11)
```

Section 2 bounds the reduced roll chord by `2eta`. Reduction modulo the
shadow half-turn is implemented by a **proper left gauge**:
`Q'=J_n^sigma Qh`, `sigma in {0,1}`. Since `J_n` fixes `n` and acts by
`-I` on `n^perp`, and `K=-K`, this preserves the projected source.
It changes `U` to `(-1)^sigma U`. If `W` is its proper three-dimensional
rotation fixing `m`, then

```
Q'=R_2 W R_1^T.
```

All three factor chords are less than `1/10`: the transport chords are
at most `a,delta`, and the reduced roll chord is at most `2eta<=1/14`.
For `0<=c<=1/10`, differentiation of `2arcsin(c/2)` gives

```
2arcsin(c/2)<=(101/100)c,
(101/100)^2(1-1/400)>1.
```

The triangle inequality for the proper rotation angle now gives

```
angle(Q') <= (101/100)(a+delta+2eta)
          = (303/50)(a+delta)=Theta<1/10.              (12)
```

This full-angle bound is derived from arbitrary original `Q`; it is
not an assumed local input.

## 4. Actual weak contacts and the adaptive torque criterion

For each cell use the following four triples `(a,b,j)`, where
`E=V_b-V_a`, `mu=E cross u`, and `V_j` is an actual supporting vertex.

| Whole closed cell | Four triples |
| --- | --- |
| 4 | `(59,55,55)`, `(36,20,36)`, `(17,4,4)`, `(17,4,17)` |
| 7 | `(43,57,43)`, `(57,61,57)`, `(57,61,61)`, `(45,34,34)` |
| 9 | `(59,55,55)`, `(58,45,58)`, `(45,34,34)`, `(45,34,45)` |

Every listed edge has norm less than `5/4`. At every corner of each
**whole** cell, the checker verifies

```
mu.(V_j-V_k)>=0 for all 62 vertices V_k.              (13)
```

These **2,480** comparisons include all four corners of cell 4 and all
three corners of cells 7 and 9. The differences are affine functions of
the unit-z ray `u`, so (13) holds at every point of each closed cell.
Only weak exposure is required: no unique-vertex exposure or strict
facet stability is assumed. If a support normal happens to vanish,
its torque is zero and remains harmless in the criterion.

The torques are `T_j(u)=V_j cross mu_j(u)`. Their support function is
`max_j z.T_j(u)`. Thus `r_cell(u)>0` means their convex hull contains
the centered ball of radius `r_cell(u)` in three-dimensional torque
space. For a rotation `Q'=exp([w]_cross)` of angle `theta=||w||>0`,
some actual contact has

```
w.T_j(u)>=theta r_cell(u).
```

The second-order rotation remainder is bounded by
`||Q'V_j-V_j-w cross V_j||<=||V_j||theta^2/2`.
One way to see this is the integral Taylor formula: the second
derivative of `exp(t[w]_cross)V_j` has norm at most
`theta^2||V_j||`. Since `||V_j||<5/2` and
`||mu_j(u)||< (5/4)||u||`,

```
mu_j(u).(Q'V_j-V_j)
  >=theta r_cell(u)-(25/16)||u||theta^2.              (14)
```

If (1) holds, (12) makes (14) strictly positive for every nonzero
`theta`. This violates (13) as an outer support inequality and excludes
even centered **closed** containment. Consequently `Q'=I`. Undoing the
gauges gives `Q=J_n^sigma h^T`, exactly the rotations in (2).
Conversely every member of these cosets has `P_n(QK)=P_n K`, using body
symmetry and central symmetry. The areas of these equal shadows are
positive, so the original `lambda>=1` must equal one. Their equal support
functions then force `t.z=0` for every planar `z`, giving `t=0`.

The parent checks the exact minimum squared Frobenius separation
between `J_m` and the full proper group:

```
min_{g in G}||J_m-g||_F^2=(106-36s)/29.
```

The gate gives `delta<=1/70`. The new checker verifies that this
separation exceeds `8(1/70)^2`. On the other hand,

```
||J_n-J_m||_F^2=8(1-(n.m)^2)<=8||n-m||^2.
```

Thus `J_n` cannot belong to `G` in the criterion's domain. The two left
cosets in (2) are disjoint and have exactly 120 members. Conjugating by
any `g in G` transports the statement to its image receiver. Replacing
`n` by `-n` preserves both its projection plane and `J_n`, giving the
antipodal statement.

At `M`, the checker also supplies explicit lower bounds for the three
torque tetrahedra:

| Cell | Centered ball radius lower bound | Tangent area slope upper bound |
| --- | --- | --- |
| 4 | `2/25` | `2` |
| 7 | `17/100` | `4/5` |
| 9 | `2/25` | `9/5` |

For each tetrahedron it verifies four **positive** signed determinant
cofactors, their exact zero vector balance, and all four facet-distance
squares strictly greater than the asserted ball-radius square.
These checks put the origin in the full-dimensional interior and
justify the stated centered balls. The exact weights, distances and
slope squares are listed in [expected_adaptive_area.json](expected_adaptive_area.json).
The slopes are `||C_i-a0 m||`; the checker verifies `C_i.m=a0` and
`||C_i-a0 m||^2=||C_i||^2-a0^2` in `Q(s)`.

## 5. The whole receiver triangle, with a continuous margin

The parent cell 7 is exactly `conv{N8,M,N7}`. Hence (3) is entirely
inside that closed cell. The new checker establishes nondegeneracy and,
at all three corners of `T`,

```
||u-M||<H=239/100000, ||u||<L=11/10.
```

Convexity of both norms extends these two bounds to the entire closed
triangle. Normalization on unit-z segments is 1-Lipschitz, giving
`delta<=||u-M||<H` throughout. The area estimate uses the **actual cell
slope**, not an unsupported assertion that the physical-area maximum
occurs at polygon corners. Namely,

```
0<=e=C_7.n-a0
    =a0(m.n-1)+(C_7-a0 m).(n-m)
    <=(4/5)delta<(4/5)H.                             (15)
```

The first term is nonpositive for unit `m,n`; the lower bound is the
global minimum. Therefore throughout the whole triangle

```
a< (24/5)H=717/62500,
eta< (29/2)H=6931/200000<1/28,
Theta< (8787/250)H=2100093/25000000<1/10.             (16)
```

For each of the four actual cell-7 torque columns, linearity gives

```
||T_j(u)-T_j(M)||
 <=||V_j||||E_j||||u-M||<(25/8)H.
```

Taking the maximum support and then the minimum over **all** unit torque
directions proves the continuous lower bound

```
r_7(u)>=17/100-(25/8)H.                              (17)
```

This support argument applies to every point, including all boundaries;
it does not infer a moving ball from corner balls or presume unchanged
facet combinatorics. Combining (16)--(17) with `||u||<11/10` leaves

```
r_7(u)-(25/16)||u||Theta
 >17/100-(25/8)H-(55/32)(8787/250)H
 =2903977/160000000>1/60.                             (18)
```

Thus criterion (1) holds on the entire closed triangle, as claimed.

Finally put `p=M.U7>0` and `c=1-1/(2*500^2)>0`. The checker proves

```
c^2||M||^2||U7||^2>p^2.
```

On the positive branch this gives
`m.(U7/||U7||)<c`, hence `||U7/||U7||-m||>1/500`.
This is an exact attained receiver extent, not a decimal search result.
