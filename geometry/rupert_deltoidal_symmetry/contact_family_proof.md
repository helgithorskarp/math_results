# Deltoidal exceptional direction: exact contact family and approach cone

Author: **six-rupert-1**, role **researcher**, 2026-09-30.

The standard deltoidal hexecontahedron remains an unresolved named Catalan
solid in the primary literature checked here. This result constructs
**proper closed projection containments with permanent boundary contacts**.
They are not Rupert passages. It also restricts small-angle approaches to
the second exceptional direction to one incident receiver cell and, for
**strict** passages, one oriented rotation-axis ray.

## Statements

Let `K` be the centered 62-vertex body generated by [verify.py](verify.py),
with coordinates from
[McCooey's standard model](https://dmccooey.com/polyhedra/DeltoidalHexecontahedron.txt).
For a nonzero vector `u`, let `P_u` be orthogonal projection onto `u`-perp;
its normalization does not affect the projection. Set `s=sqrt(5)` and

```
E  = ((3s-5)/10, (5-s)/10, 1),
r1 = (-1, -(5+s)/2, (5+3s)/10),
r2 = (-1, (-31+5s)/22, (7+s)/22).
```

The axis of `E` is the axis of `(1,phi,1+3phi)`, `phi=(1+s)/2`.
Both rays are perpendicular to `E`. Define

```
a(t) = t*r1 + (1-t)*r2,
u(epsilon,t) = E + epsilon*(a(t) cross E),
w = epsilon*a(t),
Q_w v = ((1-|w|^2)*v + 2*(w cross v) + 2*w*(w.v))/(1+|w|^2).
```

**Contact-family theorem.** For every `2/5 <= t <= 4/5` and
`0 < epsilon <= 1/100`,

```
P_u(Q_w K) is a proper subset of P_u(K).
```

This is **closed** containment: sixteen vertex-edge inequalities are
identically equalities throughout the family. No translation turns
this pair into a strict containment. Its optimal closed uniform scale is
exactly one, with translations allowed.

The nontrivial relative angle is
`2*atan(epsilon*|a(t)|)>0`. As `epsilon` tends to zero, both the receiver
direction and the inner direction `Q_w^{-1}u` approach the axis of `E`.
Consequently there is **no receiver neighborhood of this axis and no
positive angle bound excluding every nontrivial closed containment**.
The [previous stable theorem](stable_proof.md) excludes such containments
outside its 45 exceptional axes; the exception cannot be removed with
the same closed-containment conclusion. This says nothing about the
existence of a strict passage near `E`.

**Limiting-axis lemma.** Suppose nonzero rotations `Q_k` have principal
angles `theta_k -> 0`, receiver unit normals `n_k -> E/|E|`, and

```
P_(n_k)(Q_k K) + translation_k subseteq P_(n_k)(K).
```

Let `b_k` be the unit principal rotation axis, so
`Q_k = exp(theta_k [b_k]_cross)`. Every accumulation point `b` lies in

```
{alpha*r1 + beta*r2 : alpha>=0, beta>=0},
```

and has norm one. In particular `b.E=0`. The hypothesis may be closed
or strict containment. This is a necessary condition, not an existence
claim for either kind of containment.

**Incident-cell lemma.** Use the exact reflection chamber and the
`z=1` polygons generated by [orientation_certificate.py](orientation_certificate.py).
The three cells containing `E` are cells `0,2,4`. There exist positive
receiver and relative-angle bounds excluding **closed** containment when
the receiver approaches `E` through cell `2` or cell `4`, including their
boundaries, with any translation. Thus a possible small-angle passage
approaching this representative from within the chamber must eventually
use cell `0`. No explicit size for these neighborhood bounds is claimed.

For any other orbit representative the statements transport through the
verified body symmetries. Rotation axes transform as axial vectors:
conjugation by an orthogonal symmetry `S` sends the axis `b` to
`det(S)*S*b`. Merely applying a reflection to `b` without this sign
would give the wrong directed cone.

**Strict limiting-axis theorem.** Under the limiting-axis lemma's
hypotheses with **strict** containment, the rotation axes converge to
the single unit ray

```
a_star/|a_star|,
a_star = (-1,-phi,1/phi) = (-phi,-phi^2,1)/phi.
```

This is the normal of a verified body mirror plane. The theorem does
not assume a rate for `n_k -> E/|E|` relative to `theta_k`, or an analytic
path of passages. It leaves the mirror-normal ray unresolved and gives
no uniform exclusion of strict passages near `E`.

## 1. Centering and the exact containment criterion

The generated body satisfies `K=-K`. If centrally symmetric convex
polygons `A,B` obey `A+h subseteq B`, symmetry gives `A-h subseteq B`.
For every `x in A`, the midpoint of `x+h` and `x-h` belongs to `B`, so
`A subseteq B`. The same argument uses the convex open set `int(B)`
for strict containment. Hence translations cannot circumvent any
centered obstruction below.

The checker verifies that the projected receiver hull has the ordered
indices

```
H=(61,58,45,34,17,4,0,3,16,27,44,57).
```

For an edge `(a,b)` in this list, put
`e=V_b-V_a`, `n=e cross u`, and `B=n.V_a`.
All 62 outer support inequalities are verified, and every projected
turn is strictly positive. These are the complete edge halfplanes of
`P_u(K)`. Therefore it suffices to verify, for every inner vertex `V_j`,

```
n.(Q_w V_j) <= B.
```

Convexity then gives the entire projected containment. For each edge
the outer offset is positive. The checker also verifies that, at
`epsilon>0`, only its two endpoints attain this outer edge equality.

## 2. All-parameter exact checking

Write `p=a(t) cross E`, `A=a(t).a(t)`,
`n0=e cross E`, `nd=e cross p`, `b0=n0.V_a`, and `bd=nd.V_a`.
Multiplication by the positive Cayley denominator `1+epsilon^2*A`
gives the following gap polynomial:

```
N(epsilon,t) = N0 + epsilon*N1 + epsilon^2*N2 + epsilon^3*N3,
N0 = b0-n0.V_j,
N1 = bd-nd.V_j-2*n0.(a cross V_j),
N2 = A*(b0+n0.V_j)-2*(n0.a)*(a.V_j)-2*nd.(a cross V_j),
N3 = A*(bd+nd.V_j)-2*(nd.a)*(a.V_j).
```

`N_i(t)` has degree at most `i` for `i>0`; all its coefficients lie
in the ordered field `Q(sqrt(5))`. No evaluation on a sample grid is
used to decide a sign.

For completeness, a power polynomial on `[l,h]` is converted exactly
by substituting `t=l+(h-l)*x`, then using

```
x^i = sum_(k=i)^d binom(k,i)/binom(d,i) * B_(d,k)(x),
B_(d,k)(x) = binom(d,k)*x^k*(1-x)^(d-k).
```

The checker applies this conversion first in `t` and then in
`epsilon`, using degree three in both variables. Each gap is therefore
a sum of sixteen nonnegative tensor Bernstein basis functions with
exact coefficients. All **11,904 coefficients** of the **744 gaps**
are checked nonnegative.

Exactly sixteen gap polynomials are zero identically. Every other
gap is strictly positive for the whole stated domain: all four
coefficients in its highest `epsilon` Bernstein row are positive.
The corresponding basis factor `(epsilon/(1/100))^3` is positive
whenever `epsilon>0`, and the four basis functions in `t` sum to one,
including at either endpoint. This also covers `epsilon=1/100`.

The same exact conversion verifies the receiver's 744 support gaps,
all twelve positive offsets, all twelve positive turns, and its
positive `z` coordinate. Thus no assumed silhouette or missing edge
is hidden in the verification.

## 3. Why the contacts persist and why containment is proper

Let `M_E` denote reflection in `E`-perp, and `M_u` reflection in `u`-perp.
Because `a.E=0` and `u=E+w cross E`, direct substitution in the
reflection formula gives

```
Q_w = M_u M_E,
Q_w^{-1}u = E-w cross E,
P_u Q_w = P_u M_E.
```

In particular the exact inner and outer viewing directions are
opposite perturbations of `E`.

For every permanent contact `(a,b,j)`, the checker verifies a physical
segment identity

```
M_E V_j = V_a + lambda_j*(V_b-V_a),   0<=lambda_j<=1.
```

It does not infer this identity from a projected drawing. At edge
`(61,58)`, its two inner equality vertices are `55,59`, and respectively

```
lambda_55 = 3/2-3s/10,
lambda_59 = 6/11-9s/55.
```

Both lie strictly between zero and one. The other reflected contact
segments and the four equatorial vertices account for all sixteen
equalities; the output records every triple and its exact coefficient.
These identities explain why higher-order searches along the
bisector family retain zero clearance.

Containment is nevertheless proper. To attain projected receiver
vertex `61`, an inner point would have to attain equality on both
adjacent receiver edges `(57,61)` and `(61,58)`. Their inner equality
vertex sets are `{57}` and `{55,59}`, which are disjoint. A convex
combination attaining both supports could use only vertices common to
the two sets. Hence no inner point attains vertex `61`.

An inner point still lies on a positive-offset receiver support line.
This rules out strict centered containment. The centering argument
rules out a translated strict containment as well. If a scale
`lambda>1` admitted closed translated containment, recentering would
give `lambda P_u(Q_w K) subseteq P_u(K)`. At that contact line its
support would become `lambda*B>B`, a contradiction. The unscaled
closed containment is realized, so its optimal closed scale is one.

This is not a proof of the standard Rupert property. A passage requires
the projected copy to lie in the **interior** of the receiver projection,
equivalently some larger-than-unit copy to fit closed after rescaling.
A proper closed subset can share boundary points, as this one does.

## 4. The limiting cone uses uniquely projected hull vertices

[frontier_certificate.py](frontier_certificate.py) regenerates the
projected hull at `E` and verifies that every one of its twelve extremes
has a **single** 3D vertex preimage. For every hull edge `(a,b)` and
each of its endpoints `j`, set

```
n_(a,b)=(V_b-V_a) cross E,
g_(a,b,j)=V_j cross n_(a,b).
```

There are twelve distinct torque vectors. The edge probe may also
support collinear hidden vertices, so it cannot simply be assumed to
expose `V_j` at neighboring receiver directions.

Instead take a positive combination of the two incident edge normals,
arbitrarily close to the desired edge normal. It uniquely exposes the
projected extreme `V_j`, and hence `V_j` among all 62 vertices because
its preimage is unique. Transport the probe into `n_k`-perp by
orthogonal projection. Its strict finite vertex gaps persist for large
`k`, so it is still a supporting probe at `V_j`.

Centering the purported containment gives
`m_k.(Q_k V_j-V_j)<=0`. On a subsequence with `b_k -> b`, divide by
`theta_k` and use

```
(Q_k-I)/theta_k -> [b]_cross.
```

The limit is `b.(V_j cross m)<=0`. Finally let the positive combination
approach the desired edge probe. Thus `b.g<=0` for all twelve rows.
The argument applies equally to closed or strict containment, and does
not presume a differentiable path for either normal or rotation axis.

The exact checker proves that this negative polar cone is precisely
`pos(r1,r2)`. First the contacts `(17,4,4)` and `(45,34,45)` give
opposite nonzero torque vectors parallel to `E`. Their two inequalities
force `b.E=0`. Since `r1,r2` are independent, write
`b=alpha*r1+beta*r2` in that plane. The rows `(45,34,34)` and
`(58,45,58)` have respective ray evaluations

```
(0, -20/33+4s/99),
(-4/9-4s/9, 0).
```

Their strictly negative nonzero entries force `beta>=0` and `alpha>=0`.
Conversely both rays pair nonpositively with every row, which the
checker verifies. This proves equality of cones without an incomplete
enumeration or a floating convex-hull decision.

## 5. Two incident cells cannot supply small-angle containments

The chamber partition has exactly three polygons containing `E`.
For cell `2` use the supporting edge `(34,36)` and vertex `36`.
For cell `4` use edge `(61,59)` and vertex `59`.
The checker verifies all vertex support inequalities at every corner
of each **whole closed polygon**, with **434 exact comparisons**.
Linearity in the receiver chart extends these support inequalities to
the polygons. Their support offsets are positive at `E`, so their
normals remain nonzero nearby.

If a centered containment had receiver `u_k` in one of these cells,
the endpoint support inequality would be

```
((V_b-V_a) cross u_k).(V_j-Q_k V_j) >= 0.
```

The outer endpoint offset equals this vertex's offset. Dividing by
`theta_k` and passing to the limit therefore requires `-b.g>=0`.
It introduces no derivative of `u_k`: its difference from the limiting
normal is multiplied by `Q_k-I`.

For the two polar generators, the checker obtains the following
values of `-2*g.r_i`:

| Cell | Endpoint contact | On `r1` | On `r2` |
|---|---|---|---|
| 2 | `(34,36,36)` | `4-2s` | `(200-94s)/33` |
| 4 | `(61,59,59)` | `(-278+90s)/121` | `(-270+114s)/121` |

All four numbers are strictly negative. Any nonzero
`b=alpha*r1+beta*r2` with nonnegative coefficients has negative
`-2*g.b`, contradicting the required nonnegative limit.

Finally, if no positive receiver and angle neighborhood bound existed
for these two closed cells, choose offending containments with both
distances and nonzero angles at most `1/k`. The unit rotation axes
have a convergent subsequence. The preceding limiting-cone and
endpoint arguments give a contradiction. This proves the stated
qualitative neighborhood bounds. It does not estimate them and does
not exclude cell `0`, where the exact closed family lives.

## 6. Two polynomial stresses leave only the mirror-normal ray

This part concerns **strict** containment. Write

```
T_star = 5/2-s,
w = epsilon*(a(t)+z*E).
```

For any sequence of Cayley vectors whose unit axes converge into the
polar cone, this representation exists for large indices, with
`epsilon>0`, `epsilon -> 0`, `z -> 0`, and `t -> t0 in [0,1]`.
Indeed `r1,r2` span `E`-perp, their first coordinates are both `-1`,
and the perpendicular coefficient tends to zero after normalization.
There is no assumption that `z` is of order `epsilon`.

For a supporting contact `(a,b,j)` put

```
R_(a,b,j)(w) = ((1+|w|^2)*V_a
  -(1-|w|^2)*V_j-2*(w cross V_j)-2*w*(w.V_j)) cross (V_b-V_a).
```

Its gap numerator is `u.R`. Thus strict centered containment requires
`u.R>0` at every such contact. Consider these two triples, in their
listed order:

```
minus: (61,58,55), (58,45,45), (44,57,57),
plus:  (61,58,59), (45,34,45), (57,61,57).
```

All five distinct outer edges support the body over **both** cell `0`
and its image under the body reflection with normal
`h=(-phi,-phi^2,1)`. The checker verifies this at all six polygon
corners with **1,860 exact support comparisons**. Receiver points
near `E` have `u_z>0` in the `z=1` chart.

For either triple `R1,R2,R3`, let

```
M1=det(R2_xy,R3_xy), M2=det(R3_xy,R1_xy), M3=det(R1_xy,R2_xy),
D=det(R1,R2,R3).
```

The full polynomial identity is

```
M1*R1+M2*R2+M3*R3 = (0,0,D).
```

[stress_limit_certificate.py](stress_limit_certificate.py) constructs
all polynomials directly in `Q(sqrt(5))[epsilon,t,z]` and replays this
identity coefficient by coefficient. It verifies exact divisibility
of `M1` by `epsilon^2`, of `M2,M3` by `epsilon`, and of `D` by
`epsilon^2*z`. In particular `D=0` exactly at `z=0` for every
`epsilon,t`, not just to a computed order.

For both triples, the leading polynomials

```
(-M1/epsilon^2)|_(epsilon=z=0),
(-M2/epsilon)|_(epsilon=z=0),
(-M3/epsilon)|_(epsilon=z=0)
```

are **strictly positive whenever `T_star<t<=1`**. The checker converts
each into degree-two Bernstein coefficients on `[T_star,1]`. Every
coefficient is nonnegative and every highest coefficient is positive.
For the first and third polynomials, the initial coefficient is zero;
no strict positivity at `t=T_star` is inferred. All exact coefficients
are recorded in [expected_stress_limit.json](expected_stress_limit.json).

For the two determinants the quotient limits are

```
d_minus(t) = (2500-1500s)/81 + (-3000+200s)*t/81 < 0,
d_plus(t)  = (-12000+6000s)/891 + (8000+4000s)*t/891 > 0.
```

The signs hold on `[T_star,1]`, as verified exactly. Consequently,
for any fixed `t0 in (T_star,1]`, continuity provides a neighborhood
of `(epsilon,z,t)=(0,0,t0)` where all three raw weights `-Mi` are
positive whenever `epsilon>0`, and the determinant quotients keep
their stated signs. Dividing minors above proves signs only; the
stress identity always uses their **raw**, equally normalized values.

If `z<0`, use the minus triple. Then
`D=epsilon^2*z*(negative)>0`, so

```
sum_i (-Mi)*(u.Ri) = -u_z*D < 0.
```

If `z>0`, use the plus triple and obtain the same contradiction.
If `z=0`, either triple gives a zero weighted sum with all weights
positive, again incompatible with strict positive gaps. For nonzero
`z`, even closed containment is impossible in these neighborhoods.
For zero `z`, this is only a strict-containment obstruction, exactly
as the contact family requires.

It follows that a strict passage sequence with receiver in cell `0`
or its mirror image cannot have limiting `t0>T_star`.

Now let `S_h` be the body reflection just used. It fixes `E` and maps
the polar rays as **axial** vectors:

```
-S_h r1 = c*r2,   -S_h r2 = d*r1,
c=1+4s/5>0, d=(-5+4s)/11>0, c*d=1.
```

Conjugating a passage by this body symmetry preserves strict
containment and the relative angle, exchanges cell `0` with its
mirror image, and changes the limiting parameter to

```
t' = d*(1-t)/(c*t+d*(1-t)).
```

The checker verifies `T_star=d/(1+d)` and
`t'>T_star` exactly when `t<T_star`. Thus any limiting `t0<T_star`
would yield a mirrored passage sequence in the already excluded
sector. The only remaining value is `t0=T_star`, for which the
checker verifies

```
a(T_star)=(-1,-phi,1/phi)=h/phi.
```

To cover arbitrary receivers near `E`, rather than those preassigned
to cell `0`, note that `E` has positive `x,y` and lies on only the
oblique wall of the three-wall chamber. A sufficiently small
neighborhood folds into that chamber using either the identity or
`S_h`. The incident-cell lemma excludes cells `2,4` and their mirror
images for small angles. All remaining receivers are in the union
of cell `0` and its mirror image, where the two stresses apply.
Their sole surviving axis is fixed by the axial map `-S_h`.

Every accumulation point of the unit rotation axes is therefore the
same unit vector `a_star/|a_star|`. Compactness gives convergence of
the whole sequence. This proves the strict limiting-axis theorem.
It does **not** exclude the remaining mirror-normal case.
