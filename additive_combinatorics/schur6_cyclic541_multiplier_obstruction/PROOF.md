# An order-10 multiplier obstruction at modulus 541

This is an exact finite computational lemma about a restricted construction
family. It does **not** improve either bound for the classical Schur number
S(6), determine S(6), or exclude a six-colouring of [1,537] or [1,540].

## Statement

All addition and multiplication in the lemma are in F_541. A set A is sum-free
when (A+A) intersects A trivially, including sums with equal summands. Let

    H = {1,48,124,140,228,313,401,417,493,540}.

This is the multiplicative subgroup of order 10, generated by 493 = -48.

**Lemma (exact computation).** If A is a sum-free union of multiplicative
H-cosets, then |A| <= 80. Equality holds in exactly 378 sets. Up to multiplication
by a nonzero scalar there are seven such sets. They are the unions of rH over
the entries r in each row of `extremal_representatives.json`:

| Type | Coset representatives |
| --- | --- |
| 1 | 1, 4, 6, 9, 32, 59, 84, 99 |
| 2 | 1, 4, 6, 9, 37, 59, 84, 98 |
| 3 | 1, 4, 6, 9, 37, 59, 84, 99 |
| 4 | 1, 4, 7, 25, 42, 63, 86, 94 |
| 5 | 1, 4, 7, 42, 63, 86, 94, 110 |
| 6 | 1, 4, 14, 32, 43, 60, 72, 84 |
| 7 | 1, 4, 14, 32, 43, 63, 72, 84 |

Each type has 54 different scalar images, with stabilizer exactly H. No
six-colouring of F_541 minus {0} into sum-free sets can preserve every colour
under multiplication by H: six classes would cover at most 6*80 = 480 of the
540 nonzero residues. Equivalently, at least seven colours are necessary in
this family; sufficiency of seven is not asserted.

**Corollary.** Suppose c is a six-colouring of [1,540] without a monochromatic
integer x+y=z and satisfying c(x)=c(541-x). Its group K of multipliers that
preserve every colour individually has order 2 or 4. Thus any such construction
with additional colour-preserving multiplicative symmetry must use the
order-4 subgroup {1,52,489,540}. Its existence is unresolved here.

This refers to multipliers fixing the colour labels, not multipliers that
permute the six colours.

## Reduction and exhaustive proof of the lemma

There are 54 H-cosets, each of size 10. Index them from 0 to 53 by increasing
least positive representative; coset 0 is H. Make a hyperedge consisting of
the distinct coset indices of x, y, and x+y for every nonzero modular solution.
Repeated indices are retained as a smaller support, not discarded. The exact
instance has no singleton edges, 216 two-element edges, and 4392 three-element
edges. A union of cosets is sum-free if and only if its index set contains no
hyperedge. This follows directly in both directions from the definition.

Multiplication by any nonzero scalar preserves modular addition and permutes
the cosets. Every nonempty union can therefore be scaled to contain H. We
exhaust independent sets containing coset 0, separately at target sizes 8
and 9. If any larger independent set existed, one of its nine-element
subsets containing coset 0 would also be independent.

At a recursion node, S is the chosen increasing list and C is the ordered
set of still eligible larger indices. Every index in C extends S without
creating an edge. For each possible next index v, the recursion discards
indices w that complete either a two-edge {v,w} or a three-edge {u,v,w}
with u in S. It also discards smaller indices already visited. These are
exactly the new forbidden extensions: edges have at most three vertices.
The only cardinality pruning is |S|+|C| < target. Thus each eligible target
set appears exactly once, and no eligible branch is pruned.

`classify.py` performs this enumeration using integer bit sets. It visits
3523 nodes at target 8 and returns 56 sets containing coset 0; at target 9
it visits 2289 nodes and returns none. Scalar images of the 56 sets give
378 distinct sets. Canonicalizing under all 540 nonzero scalars yields
exactly the seven representatives above, each with 54 images. This proves
the upper bound, attainment, and classification.

## Separate direct check

`direct_check.py` imports no code from the hypergraph enumerator. It builds H
by testing all roots of X^10=1 and partitions the nonzero residues into its
cosets. Its state consists of the actual residue set A and the actual modular
sumset A+A. Adding a coset B replaces them by

    A union B,
    (A+A) union (A+B) union (B+B).

The extension is accepted precisely when these two sets are disjoint. Pairwise
coset sumsets are precomputed by literal modular addition. The search checks
eligibility using this definition-level condition, with no imported hyperedges,
SAT clauses, or assumed edge counts. Its full sorted target-8 catalog agrees
entry by entry with the first enumerator; its target-9 catalog is also empty.
Each resulting 80-element set is additionally checked by all ordered pairs
of its residues, including equal summands.

Both catalog generators use the same justified normalization and increasing
branch order. Their independence concerns the representation and validity
test, not independent human authorship or separate peer review. Small controls
compare every subset of the coset spaces at seven smaller prime/order pairs
with literal residue-set checking, including cases with singleton obstructions.
They cover 354 subsets and every target size in those instances.

## Proof of the corollary

A reflection-invariant integer sum-free class is modularly sum-free. Indeed,
if x+y=z mod 541 wraps, then x+y=z+541 and

    (541-x)+(541-y)=541-z.

Reflection turns this into a forbidden integer sum in the same class.
Nonwrapping sums are already prohibited, and sums equal to 541 have result
zero, which is outside the domain.

The colour-preserving multipliers form a subgroup K of F_541^*, and reflection
puts -1 in K. Since |F_541^*|=540=2^2*3^3*5, |K| is an even divisor of 540.
If 3 divides |K|, the unique subgroup of order 6 lies in K. It contains
1,129,130, and 1+129=130, so these three residues would have the same colour,
a contradiction. This can also be seen from 1+omega=-omega^2 for a nontrivial
cube root omega. If 5 divides |K|, K contains H, contradicting the lemma.
It follows that |K| divides 4; being even, it is 2 or 4.

## Context, novelty, and limits

The classical S(6) is the largest colourable interval endpoint, not the first
forced endpoint. The published lower bound 536 is from Fredricksen and Sweet,
*Symmetric Sum-Free Partitions and Lower Bounds for Schur Numbers*, EJC 7
(2000), R32. Their notion permits an exceptional reflection pair when N+1 is
divisible by 3; modulus 541 has no such exception. Their multiplicative
equivalence of symmetric partitions is prior work, not a new idea here.

- https://www.combinatorics.org/ojs/index.php/eljc/article/view/v7i1r32
- https://arxiv.org/abs/2112.03175 (Ageron et al., template constructions)
- https://arxiv.org/abs/2607.15034 (Bengone et al., July 2026; still uses 536)

The purpose of this calculation is to eliminate an attractive strong-symmetry
search family at the first prime modulus that could beat 536. The finite
order-10 extremal classification was not found in targeted primary-literature
or committed-graph searches on 2026-09-28; this is a search-relative statement,
not a historical priority claim. Cyclic and multiplier constructions in general
are established methods.

The proof relies on the displayed reduction and complete exact enumeration in
the two small programs. It is not formalized in a proof assistant. Python's
integer arithmetic and execution are trusted. There is no external dataset,
floating-point arithmetic, solver assumption, or omitted large certificate in
the lemma. Bounded exploratory SAT was used to choose the subproblem, but its
results are not part of this proof. An order-4 six-colouring probe reached its
500,000-conflict budget with status UNKNOWN; no order-4 exclusion is claimed.
