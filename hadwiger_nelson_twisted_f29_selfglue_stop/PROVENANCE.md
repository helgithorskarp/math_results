# Provenance and trust boundary

The 29 source rows are copied from
`hadwiger_nelson_frozen_centre_transfer/points.tsv` at repository source
`ef05942eeebba29628dc02f37a5792ac7d4122b8`.  That package derives the support
from the Polymath16 seven-coset construction and proves the marked-neighbour
palette property.  The present checker reconstructs the source graph and
rechecks the two finite source decisions it uses; it does not import source
code or a source certificate.

The half-turn, choice of roles `(4,1)`, complete union, active interface, and
all relation witnesses are new to this package.  The exploratory program was
run in the R4 pass-81 scratch directory.  The committed checker uses a separate
generic squarefree-radicand multiplication representation.  Positive words
can be regenerated by [produce.py](produce.py), but the checker never imports
that producer.

Trust remains in the written algebra and finite reductions, the standard
degree-eight multiquadratic basis fact, exact `Fraction` arithmetic, the
checker, CPython, ordinary hardware, and the pinned source transcription.
No SAT status, floating-point equality, omitted proof, or external solver is
trusted.  This is author-side evidence and not an independent review.
