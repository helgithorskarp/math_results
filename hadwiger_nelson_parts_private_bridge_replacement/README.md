# A fixed 508-point Parts/private-bridge replacement four-colours

The exact support here has **508 distinct plane points and 2,363 complete
unit edges**. Literal proper four- and five-colourings are checked against
every edge. It therefore fails the ordinary non-four gate and is retired as
a proposed sub-509 construction. This result covers one frozen support, not
other cuts, placements or all capped subsets of its ambient union.

## Construction and physical accounting

Start with the published, previously certified Parts509 positive parent and
the exact19-point
[Moser/palette private bridge](../hadwiger_nelson_moser_palette_private_bridge/README.md)
at its original displayed coordinates. Apply no further isometry. The bridge
shares exactly six parent points, with native labels

```text
0,150,153,158,171,313.
```

Its13 new points include four outside the parent coordinate field. The full
union has522 points and2480 unit edges, but contains the intact original
parent and is not the target support.

Retain every bridge point and delete the following14 original parent labels:

```text
201,207,57,16,328,99,272,310,316,69,130,132,330,190.
```

The support is495 remaining original points plus13 new points, exactly508.
Its edge partition is2328 original-original,21 original-new and14 new-new.
The entire19-point/34-edge bridge remains present. This is a simultaneous
replacement of14 parent vertices by13 new vertices.

The cut was selected once before colour testing. Protect the six shared
parent points. Let C be the original vertices having a unit neighbour among
the13 new points. At each step choose the unprotected remaining original
vertex maximizing

```text
|N_remaining(v) intersect C| / max(1, |N_remaining(v)|),
```

where neighbours in this formula are remaining original vertices. Break ties
by least remaining degree and then least original label. Take14 such steps.
This contact-based rule is a heuristic for choosing a single test graph;
it supplies no chromatic evidence. No other cut was tested after the
four-colouring was found.

## Exact coordinate field and complete edges

Put K=Q(sqrt3,sqrt5,sqrt11) and eta=sqrt(2-sqrt3/2), taking positive square
roots. Coordinates lie in K(eta), with the ordered K-basis

```text
B = (1,sqrt3,sqrt5,sqrt15,sqrt11,sqrt33,sqrt55,sqrt165).
```

Each row of [points.json](points.json) has32 integers divided by96: first
x in B, then x in eta*B, then y in B, then y in eta*B.

These16 field basis elements are independent. If eta belonged to K, the
K-automorphism changing the sign of sqrt3 would give an element eta' with
eta'^2=2+sqrt3/2. Then (2*eta*eta')^2=13, so sqrt13 would belong to K. This
contradicts the quadratic-subfield square classes generated by3,5,11.
Thus eta is quadratic over the degree-eight field K, and coefficient equality
is an exact equality test in the degree-sixteen compositum.

The checker reconstructs every one of the128778 unordered point pairs. It
expands flat radical monomials, using gcd multiplication of squarefree
radicals and eta^2=2-sqrt3/2. Doubling the norm keeps all coefficients integral.
It uses no floating-point screen and assumes no inherited edge list.

The source generator instead separates each coordinate as A+eta*B and uses
XOR multiplication in K. The complete ordered edge lists agree entrywise.
The checker separately loads the parent's coordinate table and the bridge's
published coordinate certificate, applies the declared deletions, and compares
all508 resulting points with the frozen table. It does not rerun the bridge's
terminal-relation census or independently review the source theorem.

## Campaign boundary

The new source relation supplied a reason to test a different parent
replacement: it has physical private contacts and a verified joint restriction,
and this selected union introduces coordinates outside K. Neither fact
predicted non-four-colourability of the cut support. The ordinary four-colouring
is decisive. No terminal census, alternate deletion order, bridge phase,
additional copy, host growth or minimization followed.

R2 retains the general private-bridge relation and amplification programme.
This R1 experiment concerns only the displayed Parts parent replacement. It
does not prove the508-point graph has unchanged terminal relation, or that
every capped subset of the522-point union four-colours. Those statements were
not tested. The parent and the source relation remain valid inputs in their
original scopes.

The support has a proper five-colouring but no non-four signal. It is not a
record candidate or a new five-chromatic construction. Parts509/2442 remains
the standing published record comparison. Pending Discovery receipts, including
the distinction between R2's rejected submission and its public source, are
unchanged by this package.
