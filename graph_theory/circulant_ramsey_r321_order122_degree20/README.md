# The degree-20 branch at order 122 for circulant \(R(3,21)\)

## Result

For \(S\subseteq\{1,\ldots,61\}\), let \(G_{122}(S)\) be the graph on
\(\mathbb Z_{122}\) in which \(u\) and \(v\) are adjacent when their circular
distance belongs to \(S\).

> **Theorem.** If \(61\notin S\), \(|S|=10\), and \(G_{122}(S)\) is
> triangle-free, then \(\alpha(G_{122}(S))\geq 21\).

Thus an order-122 circulant \((3,21)\)-coloring cannot have a 20-regular
triangle-free color. This is a partial result: degree at most 19 remains open,
so this does **not** determine \(R_C(3,21)\).

The target was prompted by Furini, Ljubić, Malaguti, Santini, and Tresoldi,
who determine \(R_C(3,n)\) through \(n=20\) and report that the cases beyond
that range remain computationally unresolved
([paper](https://arxiv.org/abs/2608.18769),
[code and certificates](https://github.com/fabiofurini/ramsey-number-lower-bounds)).
The current classical bounds are tabulated in Radziszowski's
[dynamic survey](https://www.cs.rit.edu/~spr/ElJC/sur.pdf).

## Complete reduction

Write \(x_d=1\) when distance \(d\) is blue.

1. The hypotheses give degree 20. If all members of \(S\) were even, the graph
   would be two isomorphic triangle-free graphs on 61 vertices. The published
   bound \(R(3,11)\leq 50\) gives an independent 11-set in each component, and
   hence an independent 22-set in their union. Otherwise \(S\) contains an odd
   distance other than 61, which is a unit modulo 122. Multiplication by its
   inverse therefore permits the complete symmetry normalization \(x_1=1\).
2. Every neighborhood is independent. If \(\alpha(G)\leq20\), the
   20-element neighborhood of 0 is maximal independent. Consequently every
   nonneighbor of 0 has a common blue neighbor with 0. The Tseitin variables
   generated by `maximality_clauses` encode precisely this necessary condition.
3. Translating a triangle to contain 0 gives all triangle clauses on the 61
   distance variables. A sequential counter enforces exactly ten selected
   distances, and \(x_{61}=0\) selects the 20-regular branch.
4. For every recorded 21-set \(A\), the clause
   \(\bigvee_{d\in\Delta(A)}x_d\) is necessary: otherwise \(A\) is independent.
   Multiplication by every unit modulo 122 gives further valid clauses.

The resulting formula is UNSAT. No unproved search assumption, random choice,
or heuristic maximum-clique result occurs in the final certificate.

## Certificate

[`cut_witnesses.json`](cut_witnesses.json) contains 20,270 unit-orbit
representatives. Each record stores the distance clause and an explicit
21-vertex set validating it. The generator checks every vertex set, regenerates
all 608,001 symmetry-expanded cuts, and writes a deterministic DIMACS file.

The certified instance has:

- 4,741 variables;
- 618,664 clauses (10,663 structural and 608,001 learned cuts);
- SHA-256 `5121a54a52d13c440cd834974f1adf68992a6ea391051684dc3121b185f3580e`.

The 74 MB DRAT trace is intentionally not committed. It remains reproducible
from the compact witness data and is recorded by hash in
[`proof_metadata.json`](proof_metadata.json).

## Reproduction

Keep generated CNF and proof files under `/scratch`:

```bash
python3 -m venv /scratch/r321-proof-venv
/scratch/r321-proof-venv/bin/pip install -r requirements.txt
/scratch/r321-proof-venv/bin/python generate_instance.py \
  --witnesses cut_witnesses.json \
  --output /scratch/order122-size10.cnf

/path/to/cadical --unsat -n -q \
  /scratch/order122-size10.cnf \
  /scratch/order122-size10.drat

/path/to/drat-trim \
  /scratch/order122-size10.cnf \
  /scratch/order122-size10.drat
```

The reported run used CaDiCaL 3.0.1 at commit
`c60730422e758ef1cebe7aeddf2dda31c996bf04` and `drat-trim` at commit
`2e3b2dc0ecf938addbd779d42877b6ed69d9a985`. The final checker output was
`s VERIFIED`.

## Historical calibration witness

The older order-121 construction can be recovered from two untranscribed
images in the authors' 2006
[presentation](https://www.slideserve.com/sanaa/new-lower-bounds-for-seven-classical-ramsey-numbers-r-3-q):

\[
S=\{1,3,9,17,25,27,32,40,46,51\}.
\]

The standalone checker shipped with Furini et al.'s repository independently
verified that this graph is triangle-free, has no independent 21-set, and does
have an independent 20-set. It therefore has independence number exactly 20
and certifies the known lower bound at order 121.

## Files

- `generate_instance.py`: semantic certificate validator and deterministic CNF
  generator.
- `search.py`: exploratory lazy-SAT search used to discover the clause set.
- `reconstruct_cuts.py`: independent SAT reconstruction of a vertex witness for
  each learned-cut orbit.
- `make_certificate.py`: DIMACS converter used to check the historical
  order-121 graph.
- `cut_witnesses.json`: compact semantic certificate.
- `proof_metadata.json`: hashes, counts, tool versions, and measured timings.
