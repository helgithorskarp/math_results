# A 28-vertex K4-free 7-chromatic Cayley graph

This directory gives an explicit graph proving

\[
n(7,4)\le 28,
\]

where `n(k,q)` is the minimum order of a `K_q`-free graph with chromatic
number at least `k`.  In vertex-Folkman notation this is
`F_v(2,2,2,2,2,2;4) <= 28`.

## Construction

Let

\[
\Gamma=\langle a,b\mid a^7=b^4=1,\;bab^{-1}=a^{-1}\rangle
       \cong C_7\rtimes C_4.
\]

Write its elements as `(i,j)=a^i b^j`, with `0 <= i < 7` and
`0 <= j < 4`.  Thus

```text
(i,j)(k,l) = (i + (-1)^j k mod 7, j+l mod 4).
```

Take the undirected right Cayley graph `Cay(Gamma,S)` for

\[
S=\{a^{\pm2},a^{\pm3},b^{\pm1},ab,ab^{-1},
       a^3b,a^3b^{-1},ab^2,a^{-1}b^2\}.
\]

It has 28 vertices, degree 12, and 168 edges.

## Short proof and finite certificate

The graph is vertex-transitive under left translation.  Any `K4` could
therefore be translated to one containing the identity.  The other three
vertices would form a triangle in the graph induced by `S`.  Directly from
the displayed multiplication rule, that neighbourhood graph has 24 edges and
no triangle.  Hence the Cayley graph is `K4`-free.

The verifier checks the displayed seven-colouring encoded in `verify.py`, so
`chi(G) <= 7`.  For the reverse inequality it uses the following independently
checkable argument.

1. There are exactly 56 independent 5-sets and no independent 6-set, so
   `alpha(G)=5`.
2. Six independent colour classes covering 28 vertices would include at
   least four classes of size five: with at most three, their total size is at
   most `3*5+3*4=27`.
3. There are 1,820 ways to choose four pairwise-disjoint independent 5-sets,
   leaving 1,820 distinct residual 8-sets.  The 56 explicitly checked affine
   graph automorphisms compress these residuals to 39 orbits.
4. `residual_odd_cycles.txt` supplies an odd cycle in one representative of
   every orbit.  Thus no residual is bipartite, whereas the two remaining
   colour classes of a six-colouring would make it bipartite.

Therefore `G` is not six-colourable and `chi(G)=7`.

## Reproduce

Python 3.8 or later is sufficient; there are no third-party dependencies.

```bash
python3 verify.py
```

The expected output is in `expected_summary.txt`.  The verifier reconstructs
the group, graph, independent sets, packings, and 56 automorphisms from the
definitions.  It then validates every odd cycle and proves that the 39 listed
orbits cover all 1,820 residuals.  It does not invoke or trust a SAT solver.

An optional, separately checkable SAT cross-check can be generated by

```bash
python3 generate_cnf.py six_colouring.cnf
cadical --no-binary six_colouring.cnf six_colouring.drat
drat-trim six_colouring.cnf six_colouring.drat
```

The generated formula has 168 variables and 1,037 clauses.  Generated CNF and
proof files are deliberately not required by, or committed with, the primary
structural certificate.

## Scope and literature check

The claim is the explicit upper bound only; this directory makes no lower-bound
claim.  Before publication (2026-09-20), a
live title/abstract search of arXiv and targeted web searches for `n(7,4)`,
`K4-free 7-chromatic`, and the equivalent vertex-Folkman notation found the
older general sources below but no order-28 construction.  This is evidence
for the relevance of the bound, not a claim that the search exhausts all
unindexed literature.

- N. Nenov, *On The Vertex Folkman Numbers F_v(2,...,2;r-1) and
  F_v(2,...,2;r-2)*, [arXiv:0903.3151](https://arxiv.org/abs/0903.3151).
- N. Nenov, *On the Vertex Folkman Numbers F_v(2,...,2;q)*,
  [arXiv:0903.3812](https://arxiv.org/abs/0903.3812).
- X. Xu, M. Liang, and S. Radziszowski, *Chromatic Vertex Folkman Numbers*,
  [arXiv:1612.08136](https://arxiv.org/abs/1612.08136).

The optional SAT run recorded in `sat_crosscheck.txt` agrees with the
solver-independent certificate.  Its 35.4 MB DRAT trace is intentionally
omitted under the repository's compact-evidence policy; the deterministic CNF
generator and the trace hash are retained.
