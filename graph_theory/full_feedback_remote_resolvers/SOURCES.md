# Sources and status check

The game, its partial- and full-feedback variants, and the notation
`zeta_D`/`zeta_D^*` are introduced by:

- John Jones and William B. Kinnersley, *The Directional Localization Game on
  Graphs*, arXiv:2609.01745v1 (submitted 1 September 2026),
  <https://arxiv.org/abs/2609.01745>.

In particular, Proposition 2.2(iii) proves `zeta_D^*(C_n)=2` for every
`n >= 5`; the self-contained `C_5` argument in this directory is included to
make the strict-decrease corollary independently readable.

The paper asks in Question 6.4 whether the directional localization number can
exceed two.  As checked on 20 September 2026, arXiv still lists only version 1,
and targeted searches found no later primary source settling that question or
stating the remote-resolver substitution theorem here.  This is a bounded
status check, not a claim that no related result exists under different
terminology.
