# Exact stable-transitivity number at order eight

## Result

Let a `k`-tournament be a complete directed multigraph in which the two
directions on every unordered vertex pair have total weight `k`. It has a
**transitive tournament decomposition** (TTD) if it is a sum of `k`
transitive tournaments on the same labeled vertex set. For a `k`-tournament
`T`, let `m(T)` be the least nonnegative integer `m` for which there is an
`m`-tournament `T'` such that both `T'` and `T+T'` have TTDs, and put

```text
m(n,k) = max { m(T) : T is a k-tournament on n vertices }.
```

The computation and compact certificates here prove:

> **Exact computer-assisted theorem.** `m(8,1)=2`.

More precisely, among the 6,880 isomorphism classes of tournaments on eight
vertices, exactly one has `m(T)=0`, exactly 6,783 have `m(T)=1`, and exactly
96 have `m(T)=2`.

This completes the next case after the companion result
[`m(n,1)=1` through order seven](../stable_tournaments_order7). It also
locates the first one-summand failure exactly: since the property `m(T)<=1`
is inherited by induced subtournaments, extending any of the displayed
eight-vertex obstructions proves

```text
m(n,1) >= 2  for every n >= 8.
```

Thus the claim in Davis--Schroeder that `m(n,1)>1` for every `n>=6` is false
at orders six and seven, but its conclusion becomes true starting at order
eight.

The 96 exceptional classes are all strongly connected and asymmetric. Their
score-sequence distribution is:

| score sequence | classes |
|---|---:|
| `(2,2,3,4,4,4,4,5)` | 2 |
| `(2,3,3,3,3,4,5,5)` | 2 |
| `(2,3,3,3,4,4,4,5)` | 36 |
| `(2,3,3,4,4,4,4,4)` | 18 |
| `(3,3,3,3,3,4,4,5)` | 18 |
| `(3,3,3,3,4,4,4,4)` | 20 |

These invariants are exact computational corollaries, not ingredients in the
proof of `m(8,1)=2`.

## Structural finite reduction for the lower bound

Encode a tournament on `[8]` by one bit for each pair `i<j`; an order mask is
the corresponding encoding of a transitive tournament. For transitive
tournaments `X,Y,Z`,

```text
T + X = Y + Z                                      (1)
```

if and only if the 28 pair-coordinate identities

```text
t_ij + x_ij = y_ij + z_ij
```

hold. Relabel the vertices in the low-to-high order of `X`, so that `X`
becomes the identity order `I`. On a pair where the relabeled tournament
`T*` agrees with `I`, equation (1) forces `Y` and `Z` to agree with them. On
a pair where `T*` and `I` disagree, it forces exactly one of `Y,Z` to disagree
with `I`.

Equivalently, the disagreement set of `T*` and `I` must be the disjoint union
of the inversion sets of two total orders. In poset language, the agreement
relation of `T*` and `I` must be a naturally labeled poset of dimension at
most two.

`classify_m01.cpp` implements this equivalence directly:

1. Generate all `8!=40,320` order masks.
2. For every unordered pair of order masks with disjoint inversion sets,
   mark the complement of their union. This produces exactly 2,289,971
   naturally labeled dimension-at-most-two posets.
3. Read the 6,880 nonisomorphic tournament representatives generated by
   nauty `gentourng` 2.8.6.
4. For every representative, test all 40,320 relabelings, which is equivalent
   to testing every possible added order `X`. Membership in the exact poset
   table decides (1).
5. Record explicit `X,Y,Z` data for every positive class and record all 96
   negative classes.

The equivalence proves that exhaustion of the 40,320 relabelings is a genuine
nonexistence proof, not a heuristic search. The classifier uses only fixed
width integer masks and bitsets; it has no solver, randomness, or floating
point.

For an independent negative check, `crosscheck_m1.py` encodes each exceptional
class as a CNF with 84 variables and 476 clauses. Three layers represent
`X,Y,Z`; two clauses per vertex triple exclude the two directed 3-cycles in
each layer, and a complete local truth table enforces every coordinate of
(1). CaDiCaL 1.5.3 and MiniSat 2.2.1 both returned UNSAT on all 96 CNFs. The
CNFs and solver outputs remain scratch products and are deliberately not
committed.

## Two-summand upper bound

For every exceptional tournament `T`, `cert_n8_m2.txt` lists five total
orders `X1,X2,Y1,Y2,Y3` satisfying

```text
T + X1 + X2 = Y1 + Y2 + Y3.                        (2)
```

Then `T'=X1+X2` has a TTD, and (2) is a TTD of `T+T'`, proving `m(T)<=2`.
The witnesses were found from a 140-variable, 1,176-clause truth-table CNF by
`solve_m2.py`. Their validity does not depend on the solver: the short Python
verifier reconstructs full adjacency matrices from every listed order and
checks every directed entry of all 6,783 equations (1) and all 96 equations
(2).

The 96 exhaustive one-summand failures give `m(T)>=2`, while their explicit
two-summand witnesses give `m(T)<=2`. The remaining class counts give the
full classification stated above.

## Files

- `tournaments8.txt`: 6,880 nauty representatives, upper triangle row by row.
- `classify_m01.cpp`: solver-free exhaustive one-summand classifier and
  certificate generator.
- `cert_n8_m01.txt`: one-summand witnesses and the 96 exhaustive failures.
- `solve_m2.py`: CNF generator and witness extractor for the two-summand
  upper bound.
- `cert_n8_m2.txt`: compact positive witnesses for all 96 exceptional classes.
- `verify_certificates.py`: independent definition-level checker of every
  positive equation and the class partition.
- `crosscheck_m1.py`: optional two-solver cross-check of all negative classes;
  it writes every CNF and solver output only to a caller-supplied scratch
  directory.
- `analyze_obstructions.py`: exact score, connectivity, and automorphism
  summaries for the 96 exceptional classes.
- `test_verifier.py`: focused semantic tests, including the first obstruction's
  two-summand witness.

No proof log, solver trace, DRAT file, binary, build product, or generated CNF
is committed.

## Reproduction

The recorded run used GCC 12.2.0, CPython 3.11.2, nauty 2.8.6, CaDiCaL
1.5.3, and MiniSat 2.2.1 on Debian 12. The main theorem can be regenerated
without the SAT cross-check as follows; all generated state stays under
`/scratch`.

```bash
cd graph_theory/stable_tournaments_order8
RUN=/scratch/stable_tournaments_order8_reproduction
mkdir -p "$RUN"

nauty-gentourng -q 8 "$RUN/tournaments8.txt"

g++ -std=c++20 -O3 -DNDEBUG -fopenmp \
  -Wall -Wextra -Wpedantic -Wconversion -Wshadow \
  classify_m01.cpp -o "$RUN/classify_m01"

OMP_NUM_THREADS=8 "$RUN/classify_m01" "$RUN/tournaments8.txt" \
  > "$RUN/cert_n8_m01.txt"

PYTHONDONTWRITEBYTECODE=1 python3 solve_m2.py \
  "$RUN/cert_n8_m01.txt" /path/to/cadical \
  "$RUN/m2_solver" "$RUN/cert_n8_m2.txt"

PYTHONDONTWRITEBYTECODE=1 python3 verify_certificates.py \
  "$RUN/tournaments8.txt" "$RUN/cert_n8_m01.txt" "$RUN/cert_n8_m2.txt"

PYTHONDONTWRITEBYTECODE=1 python3 -m unittest -v test_verifier.py
sha256sum -c SHA256SUMS
```

Expected classification:

```text
dimension_two_natural_posets=2289971
SUMMARY classes=6880 m0=1 m1=6783 m2_candidates=96 relabelings_tested=4553815
verified n=8: 6880 isomorphism representatives; m=0 classes=1, m=1 classes=6783, m=2 classes=96
```

The optional independent negative check is:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 crosscheck_m1.py \
  "$RUN/cert_n8_m01.txt" /path/to/cadical /path/to/minisat \
  "$RUN/m1_crosscheck" "$RUN/m1_crosscheck_summary.tsv"
```

It must report 96 UNSAT results from each solver. The exact obstruction
invariants can be regenerated with:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 analyze_obstructions.py cert_n8_m01.txt
```

## Trust boundary, source status, and novelty

The theorem trusts the proved inversion-set reduction, the inspected C++ and
Python implementations, nauty's complete nonisomorphic-tournament generation,
the compiler/interpreter, and hardware. The positive upper bound is checked
without a solver. The two SAT backends are an independent confirmation of the
96 negative instances, not the sole evidence for them. No floating point,
random sampling, or external mathematical dataset is used.

Davis and Schroeder introduced stable transitivity and `m(n,k)` in
[*Relating tournaments and permutations with xrays*](https://arxiv.org/abs/2606.21532v1),
Question 4 (2026). The inversion-set reformulation was independently stated
in the Discovery Net review of the order-seven result and is implemented here
as the main order-eight search mechanism. Targeted primary-source and committed
graph searches through 2026-09-03 found no prior exact value of `m(8,1)` or
classification of its obstructions. The theorem is therefore apparently new
relative to those searches; this is not a historical-priority claim.

The nonisomorphic representatives were generated with
[nauty and Traces](https://users.cecs.anu.edu.au/~bdm/nauty/), whose algorithms are
described by B. D. McKay and A. Piperno, “Practical graph isomorphism, II,”
*Journal of Symbolic Computation* 60 (2014), 94–112,
[DOI 10.1016/j.jsc.2013.09.003](https://doi.org/10.1016/j.jsc.2013.09.003).
