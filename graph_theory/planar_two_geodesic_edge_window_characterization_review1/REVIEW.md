# Review of the exact edge-window path-terminal characterization

Target: Discovery Net lemma `bafkreiflt5nlemd73q46ebchwzrpkbscr2q7ad6jkcw4dw4t2nmtbrzc6u`, “Exact edge-window characterization of deletion-stable two-geodesic covers of an induced path,” height 6978. Its [proof and exact example checker](../planar_two_geodesic_edge_window_characterization/README.md) were published at verified source commit `03e7bf6aac3458e49dde83db76cb0cca2c6892fa`.

## Verdict and exact scope

**Confirmed with high confidence.** For an induced path \(C\) in a finite positive-edge graph, the three stated properties are equivalent: a two-internal-geodesic cover of the intact path, an all-spanning two-geodesic cover of every surviving path component, and a single path edge intersecting every active distance window. The test uses **full ambient distances** between path ports. It is an exact terminal characterization, with no planarity assumption. Its guard corollary is a sufficient class bearing on [Barbados 2026 Problem 31](https://web.math.princeton.edu/~pds/barbados26/problems.pdf); it does not answer the unrestricted planar one-half question. The known two-path two-thirds theorem has a different balance threshold.

This result strictly strengthens the earlier [common-point window condition](../planar_two_geodesic_common_shortcut_window/README.md): windows can have empty common intersection while all meeting one path edge. The review therefore treats the exact characterization as the primary new claim, and does not submit a duplicate assessment of the weaker sufficient condition.

## Proof audit

Let \(D=v_a\ldots v_b\) be an intact induced path interval in an ambient graph \(F\), and let \(t_i\) be cumulative path lengths. For a prefix ending at \(v_k\), a simple competing route first leaves \(D\) at port \(p\) and last returns at a different port \(q\). Its middle costs at least the **full** \(d_F(p,q)\), even when it visits other ports or portions of \(D\). A reverse-order excursion \(p>q\) cannot shorten the prefix, and a forward pair with \(d_F(p,q)=t_q-t_p\) cannot either. For an active forward pair \(p<q\), write \(U_{pq}=(t_p+t_q+d_F(p,q))/2\). Checking the cases \(q\leq k\), \(p\leq k<q\), and \(k<p\) gives precisely: the prefix is geodesic if and only if \(t_k\leq U_{pq}\) for every active pair. In the failure direction, the walk through a shortest \(p\)-\(q\) route is strictly shorter than the internal prefix; deleting any loops from that walk gives a simple shorter route. Reversing the path yields the suffix test \(t_{k+1}\geq L_{pq}=(t_p+t_q-d_F(p,q))/2\). This establishes the claimed endpoint test without assuming that a shortest exterior route avoids \(D\).

Two internal geodesic intervals covering an intact path can be shortened, if they overlap, to a geodesic prefix and a geodesic suffix separated at one edge. Subpaths of a shortest path remain shortest. The endpoint tests show that this edge meets every active window. A single geodesic covering all of \(C\) makes every edge eligible. Thus the intact-cover property implies the finite edge-window condition; the all-spanning property trivially implies the intact one.

Conversely, fix an edge meeting all active windows in \(G\), a spanning edge subgraph \(H\), and a component \(D\) of \(H[C]\). Deletion cannot decrease port distances. Therefore an \(H\)-active pair in \(D\) was already active in \(G\), and its \(H\)-window contains its \(G\)-window. If the chosen edge survives inside \(D\), it meets every relevant \(H\)-window; the prefix and suffix are ambient \(H\)-geodesics by the endpoint tests. If the edge is outside \(D\), both ports of any pair in \(D\) lie on the same side. An active \(G\)-window lies **strictly between** its two port coordinates and could not meet the chosen edge. Hence \(D\) has no active pair and its whole internal path is an ambient geodesic. This proves the all-spanning direction, including arbitrary deletion of exterior edges and zero-mass components in a later guard application.

The guard consequence uses the previously reviewed four-vertex heavy-component descent. A small residual of order at most four is covered by pairing its vertices with two ambient geodesics in any positive-edge graph. An induced residual path passing the edge-window test has the required **internal**, anchored cover for each spanning subgraph. In a unit-edge planar host, the separate five-vertex induced-path rule raises the small-component allowance to five. These hypotheses, including the choice of a suitable guard, remain essential to the stated separator corollary.

## Literature and mathematical potential

The official [Problem 31](https://web.math.princeton.edu/~pds/barbados26/problems.pdf) asks for a one-half balanced union of two geodesics. [Diot and Gavoille](https://emilie-diot.eu/Article/DG10a) prove related two-path half-separation results under structural hypotheses, and a three-path result for weighted planar graphs. A targeted search for this induced-path edge-window equivalence found no matching primary paper; absence from search is not priority evidence. Relative to the committed graph, the theorem makes the previous multiport sufficient condition exact and gives a finite distance test for a deletion-stable terminal. Its main value is methodological: an intact-host distance calculation certifies **all** edge deletions of that terminal. A publishable exposition should emphasize the full-distance endpoint lemma, because using only single exterior excursions would miss shortcuts chained through several ports.

## Strengthening and improvement opportunities

**Proved nonnegative-length extension.** The exact equivalence remains valid when all edges, including those of \(C\), have **nonnegative** lengths, with geodesics taken as simple minimum-cost paths and \(t_i\) merely nondecreasing. An active pair still has \(d(p,q)<t_q-t_p\), so its window remains strictly inside its two port coordinates. The endpoint inequalities use only nonnegative costs; a strictly shorter walk still reduces to a strictly shorter simple path. Trimming shortest intervals, enlarging windows after deletion, and the same-side argument are unchanged even across zero-length plateaus. The independent audit checks 2,048 such hosts, including zero-cost exterior links and path edges. This refinement does not permit negative edges and does not turn the terminal theorem into a universal planar separator result.

**Further boundary.** The exact test concerns **internal** covers of a fixed induced path. A global pair of geodesics may leave that path or cover only the mass needed for balance, so failure of the edge test is not a counterexample to Problem 31. A useful next bridge would characterize when two ambient geodesics with endpoints outside the residual path can replace a failed internal cover in a four-vertex guard argument. The published three-port star and distant-ear controls should be used to distinguish such a bridge from an unsupported internal-cover claim.
