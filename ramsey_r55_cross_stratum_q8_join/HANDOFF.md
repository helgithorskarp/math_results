## Receiver

Input JSON contains `n:43`, `red_hex` (226 lowercase hex digits, bit k is
red for the kth lexicographic unordered pair), a canonical original `task`
ID, and `carrier_to_input`, a full permutation. The first 4q entries of
that permutation identify the original red then blue blocks; the last
43-4q identify the pinned core in its catalog order.

```sh
python3 -O -B ramsey_r55_cross_stratum_q8_join/transport.py \
  /absolute/catalog /absolute/q8-queue source.json packet.json
python3 -O -B ramsey_r55_cross_stratum_q8_join/verify_transport.py \
  /absolute/catalog /absolute/q8-queue source.json packet.json
```

The source checker validates physical block/core/maximality data and exact
core identity. It does not certify source Ramsey validity. A successful
transport checks every physical edge, all destination normalization and
red-maximality conditions, and the unique complete core guard. Its status
is `COMPLETE_Q8_PHYSICAL_TRANSPORT_VERIFIED`, with no Ramsey or original-
UNSAT claim. For non-Ramsey input the local augmentation may instead return
a literal blue five-set. A source good43 can never take that branch.

transport. Negative controls belong to the already refuted physical
branch. A good43 must take the positive branch by the imported theorem.
There is no requirement that the destination core be a listed Ramsey core.
