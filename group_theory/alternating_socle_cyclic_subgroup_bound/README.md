# The cyclic-subgroup solvability threshold for alternating socles

## Result

For a finite group `G`, let `cyc(G)` be the number of cyclic subgroups of
`G`, including the trivial subgroup, and let `omega(m)` be the number of
distinct prime divisors of `m`.

**Theorem.** Let `n >= 5` and let `G` be an almost-simple finite group with
socle `A_n`; equivalently,

```text
A_n <= G <= Aut(A_n).
```

Then

```text
cyc(G) >= 2^(omega(|G|)+2).
```

Equality holds if and only if `G = A_5`. In particular, the cyclic-subgroup
solvability conjecture of Das, Dey, and Sharma holds for every alternating
group `A_n`, every symmetric group `S_n`, and every exceptional almost-simple
extension of `A_6`.

The proof is computation-free. The companion Python program checks the exact
finite boundary, independently enumerates the exceptional `A_5` case, and
performs a finite falsification audit of the arithmetic inequalities.

## Proof

### Prime support

For `n >= 5`, the prime divisors of

```text
|A_n| = n!/2
```

are exactly the primes at most `n`. Write `pi(n)` for their number. The
classical automorphism theorem for alternating groups says

```text
|Out(A_n)| = 2  if n != 6,
|Out(A_6)| = 4.
```

Therefore adjoining outer automorphisms introduces no new prime divisor:

```text
omega(|G|) = pi(n).                                      (1)
```

Every cyclic subgroup of `A_n` is still a cyclic subgroup of `G`, so it is
enough to prove the desired lower bound for `A_n`.

### Cyclic subgroups generated by a single prime cycle

Let `p <= n` be an odd prime. Every `p`-cycle is even and hence lies in
`A_n`. The number of `p`-cycles in `S_n` is

```text
n! / (p (n-p)!).
```

Each cyclic subgroup of order `p` has exactly `p-1` generators, all of which
are `p`-cycles on the same support. Consequently the `p`-cycles alone give

```text
N_p(n) = n! / (p(p-1)(n-p)!)
       = binom(n,p) (p-2)!                              (2)
```

distinct cyclic subgroups of `A_n`.

### The uniform range `n >= 16`

Put `m=floor(n/2)`. By Bertrand's postulate there is a prime

```text
m < p < 2m <= n.
```

It is odd because `m >= 2`. Formula (2) gives

```text
cyc(A_n) >= N_p(n) >= (p-2)! >= (floor(n/2)-1)!.         (3)
```

Only `2` and the odd integers can be prime, so

```text
pi(n) <= ceil(n/2).                                     (4)
```

For every `n >= 16`,

```text
(floor(n/2)-1)! >= 2^(ceil(n/2)+2).                     (5)
```

Indeed, for even `n=2m`, inequality (5) starts at
`7! >= 2^10` when `m=8`; increasing `m` by one multiplies the left side by
`m >= 8` and the right side by `2`. For odd `n=2m+1`, it starts at
`7! >= 2^11` when `m=8`, and the same induction applies. Combining
(1)--(5) proves

```text
cyc(G) >= cyc(A_n) >= 2^(pi(n)+2) = 2^(omega(|G|)+2)
```

for all `n >= 16`.

### The finite boundary `6 <= n <= 15`

For each row, the listed odd prime `p` and formula (2) already give the
threshold. No complete enumeration of cyclic subgroups is needed.

| `n` | `p` | `N_p(n)` | `2^(pi(n)+2)` |
|---:|---:|---:|---:|
| 6 | 5 | 36 | 32 |
| 7 | 7 | 120 | 64 |
| 8 | 7 | 960 | 64 |
| 9 | 7 | 4,320 | 64 |
| 10 | 7 | 14,400 | 64 |
| 11 | 11 | 362,880 | 128 |
| 12 | 11 | 4,354,560 | 128 |
| 13 | 13 | 39,916,800 | 256 |
| 14 | 13 | 558,835,200 | 256 |
| 15 | 13 | 4,191,264,000 | 256 |

All inequalities in these rows are strict.

### The equality case `n=5`

The elements of `A_5` consist of the identity, 15 double transpositions,
20 three-cycles, and 24 five-cycles. Hence

```text
cyc(A_5) = 1 + 15 + 20/2 + 24/4 = 32 = 2^(3+2).
```

If `A_5 < G <= Aut(A_5)`, then `G` has a cyclic subgroup generated by an
element outside `A_5`, in addition to all 32 cyclic subgroups of `A_5`, so
the inequality is strict. Together with the strict finite table and the
strict factorial margin in the uniform range, equality occurs exactly for
`G=A_5`.

## Consequence and scope

Das, Dey, and Sharma conjecture that

```text
cyc(H) < 2^(omega(|H|)+2)  implies that H is solvable.
```

The theorem proves its contrapositive for the full almost-simple family with
alternating socle. It complements the existing family theorem for
`PSL(2,q)`. It does not prove the conjecture for arbitrary nonsolvable groups
or for other almost-simple socles.

The source paper and general papers on cyclic-subgroup counts were searched,
as were targeted title/abstract queries for alternating and symmetric groups.
No prior source making this threshold comparison for the alternating-socle
family was found. This is a search-relative novelty statement, not a claim of
historical priority. The element count (2), Bertrand's postulate, and the
automorphism theorem for alternating groups are classical.

## Trust boundary

The theorem trusts the classical prime support and outer automorphism orders
of alternating groups, Bertrand's postulate, and elementary permutation
counting. It uses no solver, exhaustive classification, floating point, or
generated certificate. The audit additionally trusts CPython, its exact
integer and tuple operations, and the short implementation below. Its direct
group enumeration is deliberately limited to `A_5`, the sole exceptional
case used by the proof.
