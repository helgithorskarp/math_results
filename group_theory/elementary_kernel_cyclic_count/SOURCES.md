## Trust boundary

The proof uses elementary group identities and finite-field linear
algebra; it imports no simple-group catalogue, Schur multiplier,
cohomology package, solver or numerical approximation. Conditional
quotient-family calculations use the classical A5 order distribution.
The SL(2,5) attainability example uses the classical small isomorphism
PSL(2,5)=A5, also recorded in the second primary source. The fixture
constructs and counts the projective quotient but does not construct
an isomorphism to the permutation model. This identification is used
only for that attainability example, not for either universal formula
or the conditional persistent-prime proposition.
The fixtures use literal standard group constructions and Python
integers/Fraction. They do not certify all groups, the quotient-family
