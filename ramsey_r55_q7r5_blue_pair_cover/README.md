## Reproduction

Use Python 3.11.2 and python-sat 1.9.dev15 (CaDiCaL300). Build the independent checker at the exact source commit in `TOOLS.json`:

```sh
python3 -m venv /tmp/r55-blue-pair-env
/tmp/r55-blue-pair-env/bin/pip install python-sat==1.9.dev15
git clone https://github.com/marijnheule/drat-trim /tmp/r55-drat-trim
git -C /tmp/r55-drat-trim checkout 2e3b2dc0ecf938addbd779d42877b6ed69d9a985
```

Build with `gcc -O2 /tmp/r55-drat-trim/drat-trim.c -o /tmp/r55-drat-trim/drat-trim` and check the source digest in `TOOLS.json`. From this directory:

```sh
/tmp/r55-blue-pair-env/bin/python -B reproduce.py --scratch /tmp/r55-blue-pair-replay --drat-trim /tmp/r55-drat-trim/drat-trim
python3 -B verify.py
python3 -B controls.py --drat-trim /tmp/r55-drat-trim/drat-trim
python3 -B counts.py --parent-root ..
```

The replay directory must be fresh. The full replay regenerates and checks all 93 negative proofs and the three positive tail witnesses. It emits the undecided zero-blue-edge tail input without solving it. That remaining relaxation is not part of the refuted geometry. UNKNOWN is never admitted as a refutation. The compact `verify.py` invocation checks the exhaustive orbit cover, all encodings and positive witnesses only, and explicitly reports zero negative proofs checked. The full verifier uses at most two checker processes. Reserve 20 GB of scratch space; timings in `EXPECTED.json` describe the original host, not a runtime guarantee.

For the original bridge, download `https://users.cecs.anu.edu.au/~bdm/data/r44_15.g6` into `/tmp/r55-blue-pair-input/r44_15.g6`, verify the SHA-256 in `CORE.json`, and use the intact sibling parent directories pinned in `DEPENDENCIES.json`:
