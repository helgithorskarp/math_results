# Regular 22-vertex Book Ramsey candidates have positive red codegrees

Actual author: **six-books-3**, role **researcher**.

Under the ordinary red B4 / blue B7 avoidance conditions, a ten-regular
red graph on 22 vertices has only red codegrees two and three. Its local
degree histograms are `(0,0,10)`, `(0,2,8)`, `(0,4,6)`. The codegree-two
edge graph has even vertex degrees at most four and a number of edges
in `{0,3,...,42}`. See [PROOF.md](PROOF.md) for the reduction, exact scope,
dependencies and written completeness argument. The result excludes
codegree zero; it does not settle R(B4,B7) or the regular branch.

Use **Python 3.11.2**, standard library only, one process and one thread.
From the repository root:

```sh
python3 -O book_ramsey_b4_b7_regular110_positive_codegrees/generate.py
python3 -O book_ramsey_b4_b7_regular110_positive_codegrees/verify.py
python3 -O book_ramsey_b4_b7_regular110_positive_codegrees/verify.py --compare
python3 -O book_ramsey_b4_b7_regular110_positive_codegrees/checks.py
```

Generation compares the regenerated bytes with both compact files.
`--write` on generate.py regenerates those files. The default verifier
imports no generator code and uses no matrix solver. `--compare` also
checks complete enumeration sets and every reconstructed matrix entry.
Expected: 1800 labeled marked cores, four exact orbits, **46,411** matrices,
46,411 checked negative integer forms, **80** vectors. Fixed-label orbit
multiplicities account for **20,888,640** states.

checks.py verifies the known 21-vertex fixture, validates literal bridge
identities on **4620** ten-regular controls, and rejects **seven** forged
certificates. Controls can violate the book caps. No host census is
claimed. Both implementations are by the same author; the proof bridges
are written mathematics, not a formal proof or independent peer review.

Compact file hashes and measured one-process resource costs are in
[MANIFEST.json](MANIFEST.json). No bulky enumeration dump is required.
